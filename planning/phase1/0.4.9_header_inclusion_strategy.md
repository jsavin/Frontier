## Current Status
After fixing ARC compatibility and removing conflicting type definitions, we still have header inclusion order issues.

## Root Cause Analysis
The problem is that Frontier's header chain includes system headers *after* Frontier headers are processed:

1. `main_modern.m` includes `frontier.h`
2. `frontier.h` includes `osincludes.h`
3. `osincludes.h` includes Carbon/ApplicationServices headers
4. But by this time, `standard.h` and `shelltypes.h` have already been processed

This means Frontier headers see undefined types when they're processed.

## Identified Issues

### 1. Header Inclusion Chain
- `frontier.h` → `osincludes.h` → Carbon headers
- But `standard.h` and `shelltypes.h` are processed before Carbon headers
- This causes `unknown type name` errors for `RgnHandle`, `Pattern`, `ControlHandle`, `MenuHandle`

### 2. Incomplete Type Definitions
- `FSRef` and `HFSUniStr255` are forward-declared but not fully defined
- This causes "incomplete type" errors in `shelltypes.h`

### 3. Foundation/AppKit Header Conflicts
- Some Foundation/AppKit headers have syntax errors when included in C context
- This suggests we need to be more careful about Objective-C vs C header inclusion

## Fix Strategy

### Option 1: Modify Frontier Headers (Recommended)
- Modify `frontier.h` to include our compatibility layer first
- This ensures all system types are available before Frontier headers are processed
- Minimal changes to existing codebase

### Option 2: Modify Header Inclusion Order
- Change `main_modern.m` to include system headers before `frontier.h`
- But this might cause other conflicts

### Option 3: Create Wrapper Headers
- Create wrapper headers that include system headers first, then Frontier headers
- More complex but preserves original header structure

## Recommended Approach: Option 1
Modify `frontier.h` to include our compatibility layer before including `osincludes.h`:

```c
#ifndef __FRONTIER_H__
#define __FRONTIER_H__

// Include compatibility layer first (ensures all system types are available)
#include "frontier_compat.h"

#include "osincludes.h"		/* operating system headers */
#include "frontierdefs.h"	/* global pre-processor defines */

#endif /*__FRONTIER_H__*/
```
