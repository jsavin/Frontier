# Phase 0.4: Compiler Compatibility Plan

## Overview

Phase 0.4 focuses on ensuring Frontier compiles successfully with modern compilers (Clang/LLVM, GCC) on both ARM64 and x86_64 architectures. This phase addresses compiler warnings, deprecations, and compatibility issues identified in previous phases.

## Objectives

1. **Test with modern Clang/LLVM** - Verify compilation on latest Xcode toolchain
2. **Verify GCC compatibility** - Ensure cross-platform compilation
3. **Update preprocessor directives** - Modernize compiler-specific code
4. **Fix compiler warnings** - Address all warnings and deprecations
5. **Ensure C++ standard compliance** - Update to modern C++ standards

## Tasks

### 0.4.1: Modern Compiler Testing

#### **Task: Test with Latest Clang/LLVM**
```bash
# Test compilation with latest Xcode toolchain
xcodebuild -project Frontier.xcodeproj -scheme Frontier -configuration Debug clean build

# Test specific architectures
xcodebuild -project Frontier.xcodeproj -scheme Frontier -arch arm64 -arch x86_64 clean build
```

**Success Criteria:**
- [ ] Compiles without errors on ARM64
- [ ] Compiles without errors on x86_64
- [ ] All warnings documented and categorized

#### **Task: GCC Compatibility Testing**
```bash
# Test with GCC on macOS
gcc --version
gcc -std=c17 -Wall -Wextra -fPIC -arch arm64 -arch x86_64 main.c -o Frontier

# Test with GCC on Linux (if available)
gcc -std=c17 -Wall -Wextra -fPIC -m64 main.c -o Frontier
```

**Success Criteria:**
- [ ] Compiles with GCC on macOS
- [ ] Compiles with GCC on Linux (if available)
- [ ] Consistent behavior across compilers

### 0.4.2: Preprocessor Directive Updates

#### **Task: Modernize Compiler-Specific Code**
```c
// Current (legacy)
#ifdef __MWERKS__
    #pragma options align=reset
#endif

// Target (modern)
#ifdef __clang__
    #define FRONTIER_ALIGN_8 __attribute__((aligned(8)))
#elif defined(__GNUC__)
    #define FRONTIER_ALIGN_8 __attribute__((aligned(8)))
#elif defined(_MSC_VER)
    #define FRONTIER_ALIGN_8 __declspec(align(8))
#else
    #define FRONTIER_ALIGN_8
#endif
```

**Files to Update:**
- `Common/headers/op.h` - Replace `#pragma pack(2)` with `__attribute__((packed))`
- `Common/source/FastTimes.c` - Replace PowerPC-specific timing code
- All files with `#pragma options align=*` directives

#### **Task: Update Compiler Detection**
```c
// Modern compiler detection
#if defined(__clang__)
    #define FRONTIER_COMPILER_CLANG 1
    #define FRONTIER_COMPILER_VERSION __clang_major__
#elif defined(__GNUC__)
    #define FRONTIER_COMPILER_GCC 1
    #define FRONTIER_COMPILER_VERSION __GNUC__
#elif defined(_MSC_VER)
    #define FRONTIER_COMPILER_MSVC 1
    #define FRONTIER_COMPILER_VERSION _MSC_VER
#else
    #define FRONTIER_COMPILER_UNKNOWN 1
#endif
```

### 0.4.3: Warning and Deprecation Fixes

#### **Task: Address Compiler Warnings**
```bash
# Compile with maximum warning level
clang -std=c17 -Wall -Wextra -Werror -fPIC -arch arm64 -arch x86_64 main.c -o Frontier
```

**Common Warning Categories:**
1. **Implicit function declarations** - Add missing includes
2. **Unused variables** - Remove or mark as unused
3. **Type conversions** - Add explicit casts
4. **Deprecated APIs** - Replace with modern equivalents
5. **Alignment issues** - Fix structure alignment

#### **Task: Fix Deprecated APIs**
```c
// Replace deprecated QuickTime APIs
// Old: #include <QuickTime/Movies.h>
// New: #include <AVFoundation/AVFoundation.h>

// Replace deprecated Carbon APIs
// Old: SetPort(grafPtr);
// New: Use Core Graphics APIs

// Replace deprecated memory management
// Old: NewHandle(size);
// New: malloc(size) with proper error handling
```

## Implementation Strategy

### **Phase 0.4.1: Initial Compiler Testing**
1. **Set up test environment** with latest Xcode
2. **Run initial compilation** to identify issues
3. **Document all errors and warnings**
4. **Categorize issues** by severity and type

### **Phase 0.4.2: Preprocessor Updates**
1. **Create compatibility headers** for compiler-specific code
2. **Update alignment pragmas** using strategy from 0.3.3
3. **Replace deprecated preprocessor directives**
4. **Test compilation** after each change

### **Phase 0.4.3: Warning Resolution**
1. **Address critical warnings first** (errors that prevent compilation)
2. **Fix deprecation warnings** (API compatibility)
3. **Resolve style warnings** (code quality)
4. **Document any remaining warnings** for future phases

### **Phase 0.4.4: Standard Compliance**
1. **Update build system** for modern C++ standards
2. **Fix C/C++ compatibility issues**
3. **Ensure cross-platform compatibility**
4. **Validate with multiple compilers**
