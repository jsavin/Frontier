## Part 3: Conditional Compilation Cleanup

### 3.1 Remove #ifdef FRONTIER_HEADLESS Conditionals (Where Headless is Default)
**Strategy**: Keep conditionals where UI code exists, but for headless-specific fallbacks, consider making headless the baseline.

**Current Usage** (38 occurrences across 20 files):
- `#ifdef FRONTIER_HEADLESS` guards code sections for headless-only functionality
- Since project is now 100% headless with UI separate, these conditionals can be simplified

**Approach**:
1. Invert conditionals in files that are UI-only (remove the guards, delete the code)
2. For mixed files, move headless code to be default path, wrap old UI code in `#ifdef FRONTIER_UI` or delete entirely
3. Remove guard entirely if all UI code has been deleted

**Files to Review** (count: 20 files with headless conditionals):
- `tests/headless_*.c` - These can be deleted entirely (see 3.2 below)
