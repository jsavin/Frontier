## Overview

This plan completely eliminates QuickTime dependencies from Frontier, including the UserTalk verbs that were exposed. This will resolve compilation issues and simplify the codebase.

## QuickTime Usage Analysis

### **Files Using QuickTime**
1. **`Common/source/player.c`** - Core QuickTime player implementation
2. **`Common/source/langquicktime.c`** - UserTalk verb bindings
3. **`Common/headers/osincludes.h`** - QuickTime header include
4. **`Common/headers/player.h`** - Player function declarations
5. **`Common/resources/Mac/kernelverbs.r`** - UserTalk verb definitions

### **UserTalk Verbs Exposed**
```r
resource 'EFP#' (idquicktimeverbs, "quicktime") {
    {
    "quicktime", false, {
        "open",      // quicktime.open(file)
        "play",      // quicktime.play()
        "stop",      // quicktime.stop()
        "isPlaying"  // quicktime.isPlaying()
    }
}
```

### **Phase 3: Stub Out UserTalk Verbs**

#### **Update `langquicktime.c`**
```c
// langquicktime.c - Stub out all QuickTime verbs
#include "frontier.h"
#include "standard.h"
#include "lang.h"
#include "langinternal.h"
#include "kernelverbs.h"

// Stub verb implementations
static boolean quicktimeopenverb(hdltreenode hp1, tyvaluerecord *v) {
    langerrormessage(BIGSTRING("\x2A" "QuickTime video playback is not available in this version."));
    return false;
}

static boolean quicktimeplayverb(hdltreenode hp1, tyvaluerecord *v) {
    langerrormessage(BIGSTRING("\x2A" "QuickTime video playback is not available in this version."));
    return false;
}

static boolean quicktimestopverb(hdltreenode hp1, tyvaluerecord *v) {
    langerrormessage(BIGSTRING("\x2A" "QuickTime video playback is not available in this version."));
    return false;
}

static boolean quicktimeisplayingverb(hdltreenode hp1, tyvaluerecord *v) {
    (*v).data.flvalue = false; // Always return false
    return true;
}

// Keep the function processor for compatibility
static boolean quicktimefunctionvalue(short token, hdltreenode hparam1, tyvaluerecord *vreturned, bigstring bserror) {
    switch (token) {
        case quicktimeopenfunc:
            return quicktimeopenverb(hparam1, vreturned);
        case quicktimeplayfunc:
            return quicktimeplayverb(hparam1, vreturned);
        case quicktimestopfunc:
            return quicktimestopverb(hparam1, vreturned);
        case quicktimeisplayingfunc:
            return quicktimeisplayingverb(hparam1, vreturned);
        default:
            return false;
    }
}

boolean quicktimeinitverbs(void) {
    return loadfunctionprocessor(idquicktimeverbs, &quicktimefunctionvalue);
}
```

## Implementation Steps

### **Step 1: Update Headers**
1. **Remove QuickTime include from `osincludes.h`**
2. **Remove QuickTime types from `frontier_compat.h`**
3. **Test compilation** to verify header changes work

### **Step 2: Stub Player Functions**
1. **Update `player.h`** with stub declarations
2. **Update `player.c`** with stub implementations
3. **Test compilation** to verify player stubs work

### **Step 3: Stub UserTalk Verbs**
1. **Update `langquicktime.c`** with stub implementations
2. **Test compilation** to verify verb stubs work
3. **Test UserTalk scripts** to verify error messages

### **Step 4: Update Build System**
1. **Remove QuickTime framework** from build configuration
2. **Test compilation** to verify no framework dependencies
3. **Test linking** to verify no missing symbols

### **Step 5: Documentation**
1. **Update documentation** to note QuickTime is disabled
2. **Add migration notes** for users who used QuickTime verbs
3. **Document future replacement** options (AVFoundation, etc.)

## Risk Assessment

### **Low Risk: Breaking Changes**
- **Risk**: Users who depend on QuickTime verbs will get errors
- **Mitigation**: Clear error messages explain feature is disabled
- **Documentation**: Update user documentation to note limitation

### **Low Risk: Missing Functionality**
- **Risk**: Video playback feature is completely removed
- **Mitigation**: Feature was optional and not core to Frontier
- **Future**: Can be re-implemented with modern APIs if needed

### **Low Risk: Compilation Issues**
- **Risk**: Removing QuickTime may break other dependencies
- **Mitigation**: Incremental removal with testing at each step
- **Rollback**: Easy to revert if issues arise

## Timeline

- **Day 1**: Remove QuickTime headers and update compatibility layer
- **Day 2**: Stub out player functions and test compilation
- **Day 3**: Stub out UserTalk verbs and test functionality
- **Day 4**: Update build system and final testing

## Future Considerations

### **Modern Video Playback (Optional)**
If video playback is needed in the future, implement using:
- **AVFoundation** - Modern macOS video framework
- **UI Component** - Keep video playback in UI layer, not core runtime
- **Optional Feature** - Make it a plugin or optional component

### **UserTalk Integration**
- **New Verbs** - `video.open()`, `video.play()`, etc.
- **Modern APIs** - Use AVPlayer instead of QuickTime
- **Cross-platform** - Support both macOS and other platforms

This approach completely eliminates the QuickTime dependency while maintaining UserTalk compatibility through stub implementations that provide clear error messages.
