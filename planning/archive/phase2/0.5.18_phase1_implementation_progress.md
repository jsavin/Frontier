### **Key Discoveries**

#### **1. Actual Structure Sizes**
- **Original Expectation**: 32-bit = 88 bytes, 64-bit = 80 bytes
- **Actual Reality**: 32-bit = 116 bytes, 64-bit = 88 bytes
- **Root Cause**: On 64-bit systems, `long` is 8 bytes, not 4 bytes
- **Impact**: Need to update all size validation and documentation

#### **2. Address Type Compatibility**
- **Success**: 32-bit addresses (0x12345678) work correctly in 64-bit type

- **Success**: Nil address (0) works correctly

- **Success**: Invalid versions properly rejected

### **Technical Notes**

#### **Structure Size Analysis**
```c
// On 64-bit systems:
typedef struct tydatabaserecord {
    unsigned char systemid;        // 1 byte
    unsigned char versionnumber;   // 1 byte
    dbaddress availlist;          // 8 bytes (long long)
    short oldfnumdatabase;        // 2 bytes
    short flags;                  // 2 bytes
    dbaddress views[ctviews];     // 24 bytes (3 * 8 bytes)
    Handle releasestack;          // 8 bytes (void*)
    long fnumdatabase;            // 8 bytes (long)
    long headerLength;            // 8 bytes (long)
    short longversionMajor;       // 2 bytes
    short longversionMinor;       // 2 bytes
    union {
        char growthspace[50];     // 50 bytes
        // Total: 116 bytes
    } u;
} tydatabaserecord;
```

#### **64-bit Structure Analysis**
```c
// 64-bit optimized structure:
typedef struct tydatabaserecord_64 {
    // ... same fields as above ...
    union {
        char growthspace[22];     // 22 bytes (reduced)
        // Total: 88 bytes
    } u;
} tydatabaserecord_64;
```
