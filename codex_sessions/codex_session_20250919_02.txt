    ## Background

    `langsystem7.c` still depends on classic Carbon APIs (Alias Manager, AppleEvents,
    Gestalt, menu/window globals). Those dependencies block the headless build and
    any future Windows/Linux port. During the 0.5.23 runtime work we decided to stop

    assumptions.

    ## Decisions

    - **UI Globals:** Replace direct calls into `shell`, `op`, `table`, and other UI
      globals with modern portable abstractions (or gate them behind explicit UI
      layers). Headless builds must not link any Carbon UI symbols.
    - **AppleEvents/OSA:** Document and remove the AppleEvent/OSA integration for
      headless builds. We will revisit cross-process automation once the core runtime
      is stable; for now, these features are out of scope.
    - **Alias Manager:** Modernize file handling. On macOS we will rewrite alias
      verbs on top of bookmark APIs or standard paths; on non-macOS platforms we can
      either return a structured “alias unsupported” error or map aliases to path
      strings. We do not need to preserve the exact Alias Manager semantics.
    - **Gestalt:** Reimplement the tiny set of Gestalt checks on top of the portable
      runtime info helpers.
