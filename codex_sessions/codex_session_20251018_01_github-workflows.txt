  Rewrite history

  - From the repository root, run:

  '

  That rewrites every commit where the old name/email appears.

  - Inspect: git log --format="%an <%ae>" | head
  - Force-push each branch to update the remote (e.g., git push origin YOUR_BRANCH --force-with-lease).
  - Let teammates know they’ll need to rebase or reclone if they had the old history.

  If you prefer the older tooling, git filter-branch can do it, but git filter-repo is faster and simpler.
