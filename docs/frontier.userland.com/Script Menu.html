Script Menu

When a script object's editing window is frontmost in Frontier, a menu labeled Script appears to the left of the Window menu.

Toggle Breakpoint (trl-K)

Sets and removes breakpoints from UserTalk scripts. A breakpoint is indicated by a hand character. When the script interpreter encounters a breakpoint when the script is running in Debug mode, it pauses execution.

Bundle-ize and De-Bundle

Relate to the ability to group lines in Frontier scripts. The first item creates a heading with the keyword Bundle and demotes all of the headings beneath it so that they become a single group of lines that you can then collapse. The second item is meant to be used when you are positioned on a line with the word Bundle as its first entry or on any line contained in a bundle. It undoes the effects of a Bundle-ize option.

Remove Source Code

Removes the source code from compiled scripts. They run exactly as they do in your Frontier environment, except that the user of the script doesn't get the source code.

It's best to experiment on a copy of the script, once the source code is removed it can't be brought back.
