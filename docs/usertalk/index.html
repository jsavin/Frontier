Language Overview

UserTalk is Frontier's native scripting language, built around Frontier's object database system. It features a hybrid architecture with approximately 50% UserTalk scripts and 50% C kernel implementations, providing both flexibility and performance.

Object-Oriented Design

Built around Frontier's object database system with deep integration between language and data storage.

Dynamic Typing

Variables have no type until assigned, with automatic runtime conversion and type coercion.

Cross-Platform Support

Supports both Macintosh and Windows environments with platform-specific verb suites.

JITC Compilation

Uses Just In Time Compilation ("jit-see") for optimal performance during script execution.

Core Language Features

Control Structures

for i = 1 to 5 msg (i) clock.waitSeconds (1) while not file.endOfFile (f) msg (file.readLine (f)) if answer > 6 msg ("Big family!") else msg ("Not such a big family!")

Database Integration

@table.subtable.object // Address reference local (adrTable = @someTable) adrTable^ // Dereference table db.open (filepath, false) // Open database

Error Handling

try file.delete (f) else dialog.alert ("Could not delete file")

Data Types

Basic Types

  • stringType - Text data with full 255-character support
  • numberType - Numeric values (integers and floating-point)
  • booleanType - True or False values
  • addressType - Object database references

Collection Types

  • arrayType - Heterogeneous lists with zero-based indexing
  • recordType - Key-value associative storage
  • tableType - Object database tables
  • outlineType - Hierarchical data structures

Special Types

  • scriptType - Executable UserTalk code
  • wptextType - Rich text with formatting
  • pointType - 2D coordinate pairs
  • rectangleType - 2D rectangular areas

Verb Categories

UserTalk verbs are organized into functional categories. Each category contains related verbs for specific types of operations.

UserTalk Language

  • basic
    Simple or low-level data operations
  • coercion
    Verbs for converting data types
  • keywords
    Reserved UserTalk keywords
  • operators
    UserTalk operators

Core Operations

  • db
    Open, read and manipulate object databases
  • file
    Verbs for manipulating files on disk
  • string
    Verbs for manipulating strings of text
  • table
    Verbs for managing and manipulating tables

Data Processing

  • bit
    Bitwise and logical operations
  • base64
    Convert text to/from Base64 encoding
  • re
    Fast native regular expressions
  • stack
    Verbs for creating and working with data stacks

System Integration

  • launch
    Launch programs or files
  • log
    Create log events or find a log file
  • sys
    Verbs which tell scripts about the environment
  • thread
    Create, query, stop, start and kill runtime threads

Windows and Window Objects

  • op
    Verbs for manipulating outline objects
  • script
    Verbs for manipulating script objects
  • target
    Set, get and clear the target window for the current thread
  • window
    Open, close, show, hide or resize windows
  • wp
    Verbs for manipulating wpText (styled text) objects

Web and HTML

  • html
    Verbs for rendering HTML
  • macros
    Verbs to be called within the context of rendering HTML
  • mainResponder
    The web server that underpins Manila's membership and content storage
  • webBrowser
    Open web pages on your system console
  • webServer
    Low-level web server verbs

Date and Time

  • clock
    Get or set the system time, or wait for a given time interval
  • date
    Manipulate dates or convert between different date formats

Internet

  • betty
    XML-RPC client and server
  • inetd
    Low-level TCP server
  • soap
    SOAP client and server
  • tcp
    Low-level TCP socket verbs

Application UI and Environment

  • clipboard
    System clipboard manipulation
  • dialog
    Various dialog boxes
  • editMenu
    Implements commands in the Edit menu
  • fileMenu
    Implements commands in the File menu
  • menu
    Create and manipulate menu objects and menu commands
  • mouse
    Verbs to get status of the console mouse
  • kb
    Verbs to get status of the console keyboard
  • speaker
    Verbs to make sounds using system audio

Platform-Specific

  • Windows Only:
  • com
    COM client and server verbs
  • winRegistry
    Manipulate the Windows Registry
  • winShell
    Open folders, locate files and launch files and applications
  • Macintosh Only:
  • app
    Automate apps which support AppleEvents from the App Suite
  • Finder
    Verbs for automating the Mac Finder
  • quickTime
    Open, Play or Stop media files in formats supported by QuickTime
