#title "Frontier.isRuntime"Syntax	Frontier.isRuntime ()Params	None required.Action	Determines whether the current script running environment is UserLand Frontier or Frontier Runtime.Returns	True if the script is being executed by Runtime, false otherwise.Examples	Frontier.isRuntime ()		falseNotes	This is an advanced Frontier verb of primary interest to implementers and advanced scripters. It is not necessary to understand it to use Frontier effectively for most tasks.
