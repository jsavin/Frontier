#title "Frontier.getSubFolder"Syntax	Frontier.getSubFolder (path)Params	path is a slash-delimited path, relative to Frontier's Guest Databases folder.Action	Calculates the path on disk to an folder in the Guest Databases folder.Returns	The path to the item on disk in the Guest Databases folder.Examples	Frontier.getSubFolder ("/www/")		&nbsp;&nbsp;&nbsp;&#187;"C:\\Frontier\\Guest Databases\\www\\"	Frontier.getSubFolder ("/ops/logs/")		&nbsp;&nbsp;&nbsp;&#187;"C:\\Frontier\\Guest Databases\\ops\\logs\\"	Frontier.getSubFolder ("/nonExistentFolder/")		&nbsp;&nbsp;&nbsp;&#187;"C:\\Frontier\\Guest Databases\\nonExistentFolder\\"	Frontier.getSubFolder ("")		&nbsp;&nbsp;&nbsp;&#187;"C:\\Frontier\\Guest Databases\\"Notes	This script may return a valid path to a folder that doesn't exist.	Pass the empty string as the relative path to get the path of the Guest Databases folder itself.	This verb is new in Frontier 6.0.
