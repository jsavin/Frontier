#title "Frontier.countThreads"Syntax	Frontier.countThreads ()Params	None required.Action	Counts the number of execution threads that are currently running inside of Frontier, not including the main thread.Returns	The number of threads running.Examples	Frontier.countThreads ()		2Notes	This verb is identical to "thread.getCount"	In Frontier, agents run sequentially in a single thread; all other scripts run in their own thread.	This verb is intended mainly for diagnostic purposes.See Also	"thread.getCount"
