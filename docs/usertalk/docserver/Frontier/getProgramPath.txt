#title "Frontier.getProgramPath"Syntax	Frontier.getProgramPath ()Params	None required.Action	Determines the path to the Frontier application.Returns	A string containing the full path of the Frontier application.Examples	Frontier.getProgramPath ()		"C:\\Program Files\\Frontier\\Frontier.exe"		Frontier.getProgramPath ()		"Macintosh HD:Frontier Folder:UserLand Frontier"Notes	You can extract the folder and application names from the string returned by this verb using "file.fileFromPath" and "file.folderFromPath".See Also	"file.fileFromPath"	"file.folderFromPath"	"Frontier.getFilePath"
