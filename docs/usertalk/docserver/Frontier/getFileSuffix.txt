#title "Frontier.getFileSuffix"Syntax	Frontier.getFileSuffix (type)Params	type is a Frontier object typeAction	Determines the file suffix that corresponds to that object type.Returns	The file suffixExamples	Frontier.getFileSuffix (outlineType)		"ftop"Notes	The suffix of a file determines how the application that created it interprets or deals with it.See Also	"file.type"
