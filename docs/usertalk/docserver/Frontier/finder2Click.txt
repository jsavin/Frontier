#title "Frontier.finder2Click"Syntax	Frontier.finder2Click (path)Params	path is the path name of the file where a Frontier export file is located.Action	Loads the Frontier file at path and executes it if it's a desktop script or asks the user where to store it if it is an exported object other than a desktop script.Returns	TrueExamples	Notes	The file at path must be a Frontier file.	This verb is implemented as a script.	This script is run when Frontier opens an export file.  You may wish to examine the script to learn advanced scripting techniques but the script is not necessarily intended to be called from within Frontier or to be used directly in your scripts.See Also	"export verbs"	"Frontier.new2ClickFile"	"fileMenu.open"
