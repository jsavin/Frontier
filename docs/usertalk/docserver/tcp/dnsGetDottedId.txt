#title "tcp.dns.getDottedId"Syntax	tcp.dns.getDottedId (domainName)Params	domainName is an Internet domain name.Action	Do a domain name lookup.Returns	A dotted id.Examples	tcp.dns.getDottedId ("www.scripting.com")		"206.204.24.4"	tcp.dns.getDottedId (tcp.dns.getDomainName ("206.204.24.4"))		"206.204.24.4"Notes	This verb maintains a cache in the system table, so it's faster for frequently looked up names.	It's implemented as a script.See Also	"tcp.dns.getDomainName"
