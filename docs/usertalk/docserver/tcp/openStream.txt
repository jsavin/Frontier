#title "tcp.openStream"Syntax	tcp.openStream (adr, port)Params	adr is either a DNS name, IP address, or longType specifying the host to connect to	port is the port number to connect toAction	Makes a TCP/IP connection to the specified host and port.Returns	A stream reference that can be used with "tcp.readStream", "tcp.writeStream", and "tcp.closeStream".Examples	Notes	When Frontier quits, it automatically closes any open streams.	This verb obsoletes NetEvents.openStream.
