#title "tcp.myAddress"Syntax	tcp.myAddress ()Params	None required.Action	Returns the IP address of the computer Frontier is running on.Returns	The IP address of the computer Frontier is running on, as a 4-byte numberExamples	tcp.myAddress()		-1062721023	tcp.addressDecode (tcp.myAddress())		"192.168.42.1"	tcp.addressToName (tcp.myAddress())		"ENDER" // not a real DNS name if you're not connected to the InternetNotes	Use "tcp.addressDecode" (tcp.myAddress ()) to get a human-readable IP address in dotted notation.	Use "tcp.addressToName" (tcp.myAddress ()) to get the DNS name of this computer.
