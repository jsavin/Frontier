#title "tcp.dns.getDomainName"Syntax	tcp.dns.getDomainName (dottedId)Params	dottedId is a dotted Internet address.Action	Do a reverse domain name lookup.Returns	A domain name.Examples	tcp.dns.getDomainName ("206.204.24.4")		"www.scripting.com"	tcp.dns.getDomainName (tcp.dns.getDottedId ("www.wired.com"))		"www.wired.com"Notes	This verb maintains a cache in the system table, so it's faster for frequently looked up names.	It's implemented as a script.See Also	"tcp.dns.getDottedId"	"tcp.dns.getMyDomainName"
