#title "tcp.getPeerPort"Syntax	tcp.getPeerPort (stream)Params	stream is a stream reference returned by "tcp.openStream".Action	Returns the port number of the other end of the specified stream.Returns	The port number of the other end of the specified streamExamples	local (theStream = tcp.openStream ("www.scripting.com", 80));	tcp.getPeerPort (theStream);		80	tcp.closeStream (theStream)Notes	This verb is most useful inside the callback from "tcp.listenStream".
