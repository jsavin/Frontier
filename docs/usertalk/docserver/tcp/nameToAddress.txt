#title "tcp.nameToAddress"Syntax	tcp.nameToAddress (domainName)Params	domainName is a DNS nameAction	Translates a DNS name into an IP address.Returns	The 4-byte IP addressExamples	tcp.nameToAddress ("www.scripting.com")		-825485308	tcp.addressDecode (tcp.nameToAddress ("www.scripting.com"))		"206.204.24.4"Notes	Use "tcp.addressDecode" (tcp.nameToAddress (domainName)) to get a human-readable IP address in dotted decimal notation.
