#title "tcp.examples.httpGet"Syntax	tcp.examples.httpGet (host, path, port, adrHeader)Params	host is the name or IP address of the Web server	path is the path of the document to get	port is the port to connect to	adrHeader is the optional address of a variable that will be filled with the HTTP response headerAction	Performs an HTTP GET request for the specified path on the specified server and portReturns	The body of the HTTP responseExamples	webBrowser.displayText (tcp.examples.httpGet ("localhost", "/samples.tellparams.fcgi", 80))		trueNotes	This verb is implemented as a script.
