#title "log.startup"Syntax	log.startup ()Params	None required.Action	Creates the user.log table if it doesn't exist and sets up logging preferences.Returns	True.Examples	log.startup ()		trueNotes	This verb is new in Frontier 6.	This verb is used internally by Frontier: it's called by system.startup.startupScript. You should not have to call this verb at other times. To log an item, use "log.addToGuestDatabase".
