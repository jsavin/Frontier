#title "xml.addTable"Syntax	xml.addTable (adrParent, name)Params	adrParent is the address of the table in which to create the new table.	name is the name of the new table.Action	Creates a new serialized sub-table in the table pointed to by adrparent with the	indicated name. Returns the address of the newly created table.Returns	An address.Examples	xml.addTable (@scratchpad, "TestTable")		@scratchpad.["0001\tTestTable"]See Also	"xml.addValue"
