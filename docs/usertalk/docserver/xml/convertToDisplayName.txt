#title "xml.convertToDisplayName"Syntax	xml.convertToDisplayName (name)Params	name is a string, the name of an object in a compiled XML table structure.Action	Converts the name of an object created by "xml.addValue" or a similar verb to a string suitbable for display.Returns	The resulting string.Examples	xml.convertToDisplayName ("00001000\titem")		// "item"Notes	What this verb does internally is check whether the fifth or nineth character of name is a tab, and if it is it deletes the first five or nine characters respectively.See Also	"xml.addValue"	"xml.addTable"	"xml.getAddress"
