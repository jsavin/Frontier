#title "xml.decompile"Syntax	xml.decompile (adrTable)Params	adrtable is the address of a table created by xml.compile, or a table in the same format as the one produced by xml.compile.Action	Creates tagged text that's equivalent to the database structure.Returns	A string containing the XML text that represents the database structure.Examples	xml.decompile (@xml.examples.myComputer.tableStructure)		{xml.macros.readableXML (string (xml.examples.myComputer.taggedText))}See Also	"xml.compile"	The XML-Database <a href="http://frontier.userland.com/stories/storyReader$1085">page</a> on the Frontier website.
