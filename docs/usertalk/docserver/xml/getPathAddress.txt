#title "xml.getPathAddress"Syntax	xml.getPathAddress (adrTable, path, adrResult)Params	adrTable is the address of an XML table.	path is a slash-separated path to the object you want to access.	adrResult is the address of a variable that will point to the object that path points to.Action	Travels thru the XML structure to find the object indicated by path.Returns	True if it was able to find the object, false if not.Examples	xml.getPathAddress (@xml.examples.myComputer.tableStructure, "myComputer/model", @adr); adr^		"Latitude CP"Notes	This verb is implemented as a script.See Also	"xml.getAddressList"	"xml.getAddress"
