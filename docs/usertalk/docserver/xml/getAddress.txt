#title "xml.getAddress"Syntax	xml.getAddress (adrTable, name)Params	adrTable is the address of an XML table.	name is the name of the object that we want the address of.Action	Returns the address of the first object in the indicated table with the indicated name.Returns	An address.Examples	xml.getAddress (@xml.examples.myComputer.tableStructure, "myComputer")		@system.verbs.builtins.xml.examples.myComputer.tableStructure.["0001\tmyComputer"]Notes	If there aren't any objects with that name it scriptErrors.See Also	"xml.getAddressList"
