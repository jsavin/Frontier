#title "xml.coercions.frontierValueToTaggedText"Syntax	xml.coercions.frontierValueToTaggedText (adrFrontierValue, indentlevel)Params	adrFrontierValue is the address of a Frontier object to be translated into an XML representation.	indentlevel is the minimum intendation of tabs to be used in the XML code.Action	Translates a Frontier object into an XML representation in accordance with the XML-RPC spec.Returns	The resulting XML code as a string.Notes	This verb is used by the Betty XML-RPC framework. It's called from "betty.rpc.client" and "betty.rpc.server".	The XML-RPC spec can be found at http://www.xmlrpc.com/specSee Also	"xml.coercions.structToFrontierValue"	"betty.rpc.client"	"betty.rpc.server"
