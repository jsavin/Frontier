#title "table.emptyTable"Syntax	table.emptyTable (tableAddr)Params	tableAddr is the address of a table that is to be emptied.Action	Deletes all objects contained in the table without confirmation.Returns	The number of objects that were deleted.Examples	table.emptyTable (@system.deskscripts)		15 // there were 15 scripts in this table	sizeOf (system.deskscripts)		0 // now there are noneNotes	This verb is useful when a suite is being imported and it wants to empty out a table of objects.
