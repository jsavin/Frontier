#title "table.goto"Syntax	table.goto (row)Params	row is a numberAction	Moves the table cursor to the indicated row if possible.Returns	True if the move was possible, false if it was not.Examples	Open the root table if it isn't open. Leave the cursor positioned wherever it is when you open the window. Now type and execute:		table.goto(9)			false // The root table has less than 9 rows.	Open the examples table and leave the cursor positioned wherever it is when you open the window. Now type and execute:		table.goto (1)			true  	Cursor moves to the first entry in the examples table.Notes	If row is less than 1 or greater than the number of rows in the table, Frontier returns false and leaves the cursor position unchanged.	This verb works on the target window. By default, the target window is the topmost window, but you can use target.set to change it.See Also	"table.go"	"table.gotoAddress"	"table.gotoName"
