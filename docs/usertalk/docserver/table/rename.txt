#title "table.rename"Syntax	table.rename (addr, name)Params	addr is the Object Database address of the object to be renamed.	name is a string providing the new name for the object at location addr.Action	Changes the name of the object stored in the Object Database at addr to name.Returns	TrueExamples	With the examples table frontmost, type and execute:		table.rename(@examples.name,"moniker")			true	With the examples table frontmost, type and execute:		table.rename(@scratchpad.x,"y")			true	Note that the scratchpad table need not even be open for this change to occur.
