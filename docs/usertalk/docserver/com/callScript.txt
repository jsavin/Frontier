#title "com.callScript"#platform "Win"Syntax	com.callScript (scriptCode, language, mainRoutine, parameters)Params	scriptCode, a string, is the actual script. This script should be composed of subroutines and functions.	language, a string, is the script's language, such as VBScript, JScript, or PerlScript.	mainRoutine, a string, is the name of the function or subroutine in the script to call.	parameters is a list, the parameters to pass to the script that's called.Action	Calls an Active Scripting Engine script with parameters and returns the result.Returns	Whatever is returned by the Active Engine Script.Examples	com.callScript ("Function main (param)\rmain = param\rEnd Function", "VBScript", "main", \{10})		"10"Notes	This verb is Windows-specific. It requires that the Microsoft Script Control is installed.	The winShell verbs make use of com.callScript in order to script the Windows shell.	This verb is new in Frontier 6.0.See Also	"winShell Verbs"
