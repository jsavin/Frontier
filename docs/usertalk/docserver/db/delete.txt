#title "db.delete"Syntax	db.delete (f, path)Params	f is a filespec or path string of a Frontier object database file that has been opened with db.open.	path is a valid UserTalk address string, indicating the location in the database where you want to delete information.Action	Deletes the value in the location indicated by path.Returns	TrueExamples	db.delete ("System:Frontier:old.root", "examples.age")		true	db.delete ("System:Frontier:old.root", "examples.[\"doesn't exist\"]")		error: "Can't delete "doesn't exist" because it hasn't been defined."Notes	The database file specified in the parameter "f" must be opened using "db.open" before calling this verb.	path can be a full or partial database address; the paths table of the target database is used to interpret it.	db.delete (f, path) is equivalent to delete (@path^) when referring to Frontier's current object database.	To save changes you make to a database, you must call "db.save" before "db.close".See Also	"db.open"	"db.setValue"	"delete"
