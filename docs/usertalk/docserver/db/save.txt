#title "db.save"Syntax	db.save (f)Params	f is a filespec or path string of a Frontier object database file that has been opened with db.open.Action	Saves changes made to the indicated database.Returns	TrueExamples	db.save ("System:Frontier:old.root")		trueNotes	The database file specified in the parameter "f" must be opened using "db.open" before calling this verb.	db.save (f) is equivalent to "fileMenu.save" when referring to Frontier's current object database.See Also	"db.open"	"fileMenu.save"
