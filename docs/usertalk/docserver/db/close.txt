#title "db.close"Syntax	db.close (f)Params	f is a filespec or path string of a Frontier object database file that has been opened with db.open.Action	Closes the indicated Frontier object database file.Returns	TrueExamples	db.close ("System:Frontier:old.root")		trueNotes	The database file specified in the parameter "f" must be opened using "db.open" before calling this verb.	This verb does not save changes. To save changes you've made to the database, you must call "db.save".See Also	"db.open"	"db.save"	"fileMenu.close"	"file.close"
