#title "db.getModDate"Syntax	db.getModDate (f, path)Params	f is a filespec or path string of a Frontier object database file that has been opened with db.open.	path is a valid UserTalk address stringAction	Retrieves the last modification date of the item whose path is supplied and returns it.Returns	The last modification date of something stored in a Frontier object database.Examples	db.getModDate ("System:Frontier:old.root", "examples.age")Notes	The database file specified in the parameter "f" must be opened using "db.open" before calling this verb.	Modification dates are only stored for non-scalar values like tables and outlines.	path can be a full or partial database address; the paths table of the target database is used to interpret it.See Also	"timeModified"	"db.open"	"db.getValue"
