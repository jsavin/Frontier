#title "thread.evaluateTo"Syntax	thread.evaluateTo (s, adr)Params	s is a string value containing a valid UserTalk expression.	adr is the address of a database cell in which to store the result.Action	Compiles the string s as a Frontier script and interprets it in a newly-created thread, storing the result of the expression in the cell at adr.Returns	The numeric id of the new thread.Examples	id = thread.evaluateTo ("calculatePiTo1000Places ()", @scratchpad.pi)		127Notes	The address passed in adr cannot be the address of a local variable, because that variable may have gone out of scope when the script being evaluated finishes.	This verb is implemented as a script.See Also	"thread.evaluate"	"evaluate"
