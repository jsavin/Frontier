#title "thread.evaluate"Syntax	thread.evaluate (s)Params	s is a string value containing a valid UserTalk expression.Action	Compiles the string s as a Frontier script and interprets it in a newly-created thread.Returns	The numeric id of the new thread.Examples	id = thread.evaluate (\"states.looper()\")		127	id = thread.evaluate (\"myLengthyScript(\\"hello\\")\")		128Notes	The caller of this verb cannot directly determine the result of the expression s. To store the result in a specified location, use thread.evaluateTo.See Also	"thread.evaluateTo"	"evaluate"
