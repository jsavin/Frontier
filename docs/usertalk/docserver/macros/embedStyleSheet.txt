#title "embedStyleSheet"Syntax	embedStyleSheet (sheetName, adrPageTable)Params	sheetName is the optional name of the style sheet to embed. If not supplied, the default style sheet will be embedded.	adrPageTable is the optional address of the page table.Action	Renders a style sheet and embeds it in a web page.Returns	A string, the rendered style sheet.Examples	embedStyleSheet ()		"p, li, td, h1, h2, h3, h4, h5, h6 { font-family: Arial, Verdana, Helvetica, Geneva}..."Notes	embedStyleSheet is preffered to linkStyleSheet for dynamic sites.	This macro is stored at html.data.standardMacros.embedStyleSheet.	This macro is new in Frontier 5.1.See Also	"linkStyleSheet"
