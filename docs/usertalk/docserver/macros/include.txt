#title "include"Syntax	include (f)Params	f is the path on disk to a text or HTML file to include in a web page.Action	Reads the file from disk and includes the contents of the file in a web page.Returns	A string, the contents of the file.Examples	include ("Power HD:Frontier:Read Me.html")		"&lt;html>\r&lt;head>\r&lt;title>Frontier 6: Macintosh&lt;/title>\r&lt;meta name=\"generator\" content=\"Frontier 6.0 MacOS\">&lt;/head>\r&lt;body bgcolor=\"#FFFFFF\" alink=\"#008000\" vlink=\"#800080\" link=\"#0000FF\" text=\"#000000\">..."Notes	This macro is stored at html.data.standardMacros.include.See Also	"cSourceFile"
