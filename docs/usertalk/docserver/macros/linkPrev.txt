#title "linkPrev"Syntax	linkPrev (linetext)Params	linetext is a string, the visible text that links to the previous page.Action	Generates a link to the previous page in the #nextPrevs outline.Returns	The HTML string.Example	linkPrev ("Previous")		"&lt;a href="pageOne.html">Previous&lt;/a>"Notes	The nextPrevs outline is an outline of Frontier addresses, listing the order of your pages.	See the tutorial page on <a href="http://frontier.userland.com/tutorial/websites/nextPrevLinks">NextPrev Links</a>.	This macro is stored at html.data.standardMacros.linkPrev.See Also	"linkNext"
