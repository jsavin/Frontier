#title "frontierLogo"Syntax	frontierLogo ()Params	None required.Action	Builds HTML that displays a Scripted By Frontier GIF that links to the Frontier home page.Returns	A string, the HTML.Examples	frontierLogo ()		"&lt;a href=\"http://www.scripting.com/frontier5/\">&lt;img src=\"http://www.scripting.com/logos/logoMacOS.gif\" height=38 width=150 border=0>&lt;/a>"Notes	The URL for the logo depends on which operating system you're using.	This macro is stored at html.data.standardMacros.frontierLogo.See Also	"builtWithBBEdit"
