#title "linkNext"Syntax	linkNext (linetext)Params	linetext is a string, the visible text that links to the next page.Action	Generates a link to the next page in the #nextPrevs outline.Returns	The HTML string.Example	linkNext ("Next")		"&lt;a href="pageTwo.html">Next&lt;/a>"Notes	The nextPrevs outline is an outline of Frontier addresses, listing the order of your pages.	See the tutorial page on <a href="http://frontier.userland.com/tutorial/websites/nextPrevLinks">NextPrev Links</a>.	This macro is stored at html.data.standardMacros.linkNext.See Also	"linkPrev"
