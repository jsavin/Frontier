#title "bodyTag"Syntax	bodyTag (pageTable)Params	pageTable is the optional address of the current page table.Action	Builds a &lt;body...> tag based on #background, #bgcolor, #alink, #vlink, #link, and #text directives.Returns	The string containing the &lt;body...> tag.Examples	bodyTag ()		"&lt;body bgcolor=\"#FFFFF0\" alink=\"#008000\" vlink=\"#800080\" link=\"#0000FF\">"Notes	This macro is stored at html.data.standardMacros.bodyTag.See Also	"metaTags"
