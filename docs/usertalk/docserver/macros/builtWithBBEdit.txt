#title "builtWithBBEdit"Syntax	builtWithBBEdit ()Params	None required.Action	Builds HTML that displays a Built With BBEdit GIF that links to the Bare Bones website.Returns	The string containing the HTML.Examples	builtWithBBEdit ()		"&lt;a href=\"http://www.barebones.com/builtwith.html\">&lt;img src=\"http://www.barebones.com/bbedit_badge1.gif\" alt=\"Built With BBEdit\" border=0>&lt;/a>"Notes	This macro is useful for people building websites with Frontier and BBEdit.	This macro is stored at html.data.standardMacros.builtWithBBEdit.See Also	"frontierLogo"
