#title "webBrowser.displayText"Syntax	webBrowser.displayText (s)Params	s is a string containing an HTML document.Action	Writes the string to a file and loads that file in the current Web browser.Returns	True.Examples	webBrowser.displayText ("<b>Hello!</b>")		trueNotes	This verb is useful for debugging scripts that output HTML.	This verb is implemented as a script.See Also	"webBrowser.openDocument"	"webBrowser.openUrl"
