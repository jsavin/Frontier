#title "webBrowser.openURL"Syntax	webBrowser.openURL (URL, window)Params	URL is a URL	window is the optional index of a window.Action	Opens the specified URL in the user's web browser.Returns	True on Macintosh, "L" on Windows.Examples	webBrowser.openURL ("http://www.scripting.com/")		trueNotes	The window parameter is ignored on Windows	This verb is implemented as a script.See Also	"webBrowser.openDocument"
