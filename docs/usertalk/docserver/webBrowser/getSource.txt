#title "webBrowser.getSource"Syntax	webBrowser.getSource (URL, timeout)Params	URL is the URL whose contents will be returned	timeout is the number of seconds you're willing to waitAction	Returns the source of the requested page using the currently running Web browser.Returns	The source of the requested pageExamples	Notes	This verb is implemented as a script.	On Mac OS, this verb uses the currently running Web browser to get the front window's source.	On Windows, this verb retrieves the page from the server directly.See Also	"webBrowser.getFrontWindowSource"	"tcp.examples.httpGet"
