#title "webBrowser.getFrontWindowSource"#platform "MacOS"Syntax	webBrowser.getFrontWindowSource ()Params	None required.Action	Gets the source of the page being displayed in the front window of the running Web browser.Returns	The source of the page being displayed in the front window of the running Web browser.Examples	webBrowser.getFrontWindowSource ()		"<html>\r\n<head>\r\n<title>Scripting News: 4/24/99</title>\r\n<meta name=\"generator\" content=\"Frontier 6.0b7 WinNT\">..."Notes	This verb is implemented as a script.	When using MSIE 3.0.1 or higher for Mac OS, this verb takes advantage of a direct connection to the browser to get the front window's source with no network activity.	When using other browsers, this verb retrieves the page from the server again.See Also	"webBrowser.getFrontWindowURL"
