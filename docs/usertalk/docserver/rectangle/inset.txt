#title "rectangle.inset"Syntax	rectangle.inset (rect, dh, dv)Params	rect is a rectangle object.	dh is the number of pixels by which to reduce the width of rect.	dv is the number of pixels by which to reduce the height of rect.Action	Reduces the size of rect.Returns	The resulting rectangleExamples	rectangle.inset (examples.windowat, 10, 10)		» 20, 40, 100, 220	The rectangle starts out with values of 10, 30, 110, 230.See Also	"rectangle.outset"
