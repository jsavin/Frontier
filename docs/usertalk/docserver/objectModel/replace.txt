#title "objectModel.replace"Syntax	objectModel.replace (obj)Params	obj is the specifier of the object to be replaced by an object to be inserted.Action	Creates a typeInsertionLoc descriptor record specifying insertion replacing obj.Returns	A binary value containing the descriptor record.Examples	with objectModel \{move (document [1].paragraph [1], replace (document [1].paragraph [1]))\}		trueNotes	This verb can only be used with applications whose verbs are based on the object model protocol.	This verb is implemented as a small script that calls "insertionLoc".See Also	"objectModel.before"	"objectModel.after"	"objectModel.beginningOf"	"objectModel.endOf"	"core.create"	"core.move"
