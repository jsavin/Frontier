#title "objectModel.before"Syntax	objectModel.before (obj)Params	obj is the specifier of the object before which an object is to be inserted.Action	Creates a typeInsertionLoc descriptor record specifying insertion immediately preceding obj, in obj's container.Returns	A binary value containing the descriptor record.Examples	with objectModel \{create (window, 0, 0, before (window [1]))\}		trueNotes	This verb can only be used with applications whose verbs are based on the object model protocol.	This verb is implemented as a small script that calls "insertionLoc".See Also	"objectModel.after"	"objectModel.beginningOf"	"objectModel.endOf"	"objectModel.replace"	"core.create"	"core.move"
