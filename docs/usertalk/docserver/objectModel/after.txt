#title "objectModel.after"Syntax	objectModel.after (obj)Params	obj is the specifier of the object after which an object is to be inserted.Action	Creates a typeInsertionLoc descriptor record specifying insertion immediately following obj, in obj's container.Returns	A binary value containing the descriptor record.Examples	with objectModel \{create (window, 0, 0, after (window [1]))\}		trueNotes	This verb can only be used with applications whose verbs are based on the object model protocol.	This verb is implemented as a small script that calls "insertionLoc".See Also	"objectModel.before"	"objectModel.beginningOf"	"objectModel.endOf"	"objectModel.replace"	"core.create"	"core.move"
