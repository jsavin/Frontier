#title "bit.clear"Syntax	bit.clear (bits, bitnum)Params	bits is a 32-bit number.	bitnum is a number between 0 and 31.Action	Turns off the indicated bit and returns the result.Returns	A 32-bit number containing the bit pattern in bits with bit number bitnum turned off.Examples	bit.clear (255, 3) // only bit 3 is off		247	bit.clear (bit.clear (255, 3), 4) // bits 3 and 4 are off		231See Also	"bit.get"	"bit.set"
