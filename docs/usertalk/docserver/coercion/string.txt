#title "string"Syntax	string (value)Params	value is the object whose datatype you wish to convert to stringType.Action	Converts value to a string representation.Returns	The resulting string if coercion is successful, an error condition otherwise.Examples	string (12)		"12"	string (point.set (12, 24))		"12,24"	The point.set verb creates an object of datatype point, which is then coerced to a string in this example.		string (clock.now ())		"1/22/98; 11:14:54 PM"Notes	There is usually an obvious conversion correspondence between value and its string representation.	The results of the examples you see throughout this manual result from Frontier automatically coercing the actual return value to a string for display.	Unlike most other coercion verbs, the string verb will accept complex values, such as outlines and word processing text objects.See Also	"string4"	"displayString"
