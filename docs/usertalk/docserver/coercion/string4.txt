#title "string4"Syntax	string4 (value)Params	value is usually a four-character string. It can, however, be any value that can be represented in four bytes and whose datatype you wish to coerce to string4Type.Action	Converts value to have a datatype of string4Type.Returns	The four-character string resulting from the conversion.Examples	string4 ("LAND")		'LAND'	scratchpad.idprogram = string4 ("abcd")		'abcd'Notes	The string4 datatype uses less storage than the string datatype applied to a string of the same length.See Also	"string"
