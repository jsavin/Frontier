#title "search.globalReplace"Syntax	search.globalReplace (searchString, replaceString)Params	searchString is the string of characters for which you wish to search in the database.	replaceString is the string of characters to be used to replace all occurrences of searchStringAction	Searches from the present cursor position to the end of the database, replacing all occurrences of searchString with replaceString.  If search.params.wraparound is true (the "Wrap around" option in the Find & Replace dialog), the search will wrap back 	around to the cursor's position again, updating the entire database.Returns	The number of occurrences of searchString located and replacedExamples	search.globalReplace ("Test", "Trial")		» 3Notes	This verb is implemented as a script.See Also	"search.replaceAll"	"search.findNext"
