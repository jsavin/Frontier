#title "search.dialog"Syntax	search.dialog ()Params	None requiredAction	Displays the Frontier find-and-replace dialog box.Returns	TrueExamples	search.dialog ()		» trueNotes	If you use this verb and the dialog is already open, Frontier brings the dialog to the front and returns true.	This verb - including the Find & Replace dialog window - is implemented as a script.See Also	"search.find"	"search.replace"
