#title "search.reset"Syntax	search.reset ()Params	None requiredAction	Resets the scope of the search.Returns	TrueExamples	search.reset ()		» trueNotes	All of the present search parameters remain in effect. Only the scope of the search operation is changed so that an in-process search, if there was one, is stopped and an entirely new search is initiated.See Also	"search.dialog"
