#title "script.setLanguage"#platform "MacOS"Syntax	script.setLanguage (addr, name)Params	addr is the Object Database address of a script object.	name is the name of the language to be set for the script.Action	Sets the language of the specified script object to name.Returns	True if name specifies an available language, false otherwise.Examples	script.setLanguage (@myScript, "AppleScript")		truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	The language of a newly-created script object is always UserTalk.	If a scripting component for the named language is unavailable, the script object is left unchanged, and the verb returns false.	This verb is not supported by Frontier Runtime.See Also	"script.getLanguage"
