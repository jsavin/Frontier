#title "misc.createPublisher"Syntax	misc.createPublisher (appID, obj, file)Params	appID is a value identifying the application to which this verb is addressed. It can be a string4 containing the application signature, a binary value obtained by calling sys.browseNetwork or a string containing a valid network address.	obj is the specification of the objects that are to be published.	file is the full file system path of the edition file to contain the publication.Action	Instructs the application identified by appID to create a publication in file consisting of the specified objects.Returns	TrueExamples	Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This verb is intended to be used only with applications that support the Miscellaneous Standards suite of Apple events and the Edition Manager. Typically, an application's verb table will include high-level verbs that correspond to all of the events that 	it supports, so scripts should not have to call the misc verbs directly.
