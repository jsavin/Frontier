#title "misc.endTransaction"Syntax	misc.endTransaction (appID, transactionID)Params	appID is a value identifying the application to which this verb is addressed. It can be a string4 containing the application signature, a binary value obtained by calling sys.browseNetwork or a string containing a valid network address.	transactionID is a number identifying the transaction that is complete.Action	Instructs the application identified by appID to end the transaction identified by transactionID.Returns	TrueExamples	misc.endTransaction ("*:Quadra:MacDatabase", scratchpad.transactionID)		» truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This verb is intended to be used only with applications that support the Miscellaneous Standards suite of Apple events. Typically, an application's verb table will include high-level verbs that correspond to all of the events that it supports, so 	scripts should not have to call the misc verbs directly.	transactionID should be the value returned as the result of a call to misc.beginTransaction.	See the Apple Event Registry for details on the use of this IAC verb.See Also	"misc.beginTransaction"	"transactionEvent"
