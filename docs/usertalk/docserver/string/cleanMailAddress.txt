#title "string.cleanMailAddress"Syntax	string.cleanMailAddress (string)Params	string is an email address in any common format.Action	Converts the address into the format "address (name)".Returns	The resulting string.Examples	string.cleanMailAddress ("\"Avraham Tzur\" &lt;tzur@interval.com>")		"tzur@interval.com (Avraham Tzur)"	string.cleanMailAddress ("Carl Stork &lt;carls@microsoft.com>")		"carls@microsoft.com (Carl Stork)"	string.cleanMailAddress ("wesley@scripting.com")		"wesley@scripting.com"Notes	This verb is implemented as a script.
