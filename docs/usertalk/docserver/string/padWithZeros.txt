#title "string.padWithZeros"Syntax	string.padWithZeros (num, places)Params	num is a number	places is the desired length of the resulting stringAction	Adds zeros to the beginning of the string until it has places digits.Returns	The resulting string.Examples	string.padWithZeros (7, 3)		"007"	string.padWithZeros (123, 3)		"123"	string.padWithZeros (1234, 3)		"1234" // doesn't truncate longer numbersNotes	This verb is implemented as a script.
