#title "string.mid"Syntax	string.mid (string, index, count)Params	string is the string from which you wish to extract characters.	index is a number indicating the position of the first character to be extracted from string.	count is a number indicating the number of characters starting from position index to extract from string.Action	Creates a new string consisting of count characters copied from string beginning at the index position.Returns	The resulting string.Examples	string.mid ("Beeblebrox", 2, 3)		eeb	string.mid ("Beeblebrox", 2, 9)		eeblebroxErrors	Using a negative value for index generates an error message.See Also	"string.nthChar"
