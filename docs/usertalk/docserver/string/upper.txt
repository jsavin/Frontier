#title "string.upper"Syntax	string.upper (string)Params	string is the string whose characters are to be operated on by the verb.Action	Converts all the characters in string to upper case.Returns	The resulting string.Examples	string.upper ("Ron Darling")		RON DARLING	string.upper ("NeW YoRk mEtS")		NEW YORK METS	string.upper ("POT ROAST")		POT ROASTSee Also	"string.lower"
