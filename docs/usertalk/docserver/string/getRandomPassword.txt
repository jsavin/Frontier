#title "string.getRandomPassword"Syntax	string.getRandomPassword (numChars)Params	numChars is the number of characters the password should contain.Action	Creates a random password of alphanumeric and punctuation characters.Returns	The password.Examples	string.getRandomPassword (5)		"X=BVY"	string.getRandomPassword (8)		"JAG$IZI3"Notes	This verb is new in Frontier 5.1.
