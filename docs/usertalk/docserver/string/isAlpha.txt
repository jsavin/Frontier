#title "string.isAlpha"Syntax	string.isAlpha (character)Params	character is a single character enclosed in single or double quotation marks.Action	Tells whether the specified character is a letter or not.Returns	True if the character is a letter.Examples	string.isAlpha ('a')		true	string.isAlpha ('A')		true	string.isAlpha ('1')		false	string.isAlpha ('&')		falseErrors	Attempting to assign a multi-character string as character results in an error because Frontier cannot coerce a multiple-character string to be a character.Notes	See Also	"string.isNumeric"	"string.isPunctuation"
