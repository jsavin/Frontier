#title "string.getFileUrl"Syntax	string.getFileUrl (url)Params	url is a string.Action	Parses the string as if it were a file:/// URL and returns a string that's a path to the file it points to.Returns	A string containing a file path.Examples	string.getFileUrl ("file:///C:/WINNT/Java/Classes/")		"C:\\WINNT\\Java\\Classes\\"	string.getFileUrl ("file:///C:/Program%20Files/Microsoft%20Office") //urls can be URL-encoded		"C:\\Program Files\\Microsoft Office"	string.getFileUrl ("file:///Macintosh HD/Apps/Adobe Photoshop:") //Mac-style file paths		"Macintosh HD:Apps:Adobe Photoshop:"Notes	This verb is implemented as a script.See Also	"string.urlEncode"
