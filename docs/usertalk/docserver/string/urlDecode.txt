#title "string.urlDecode"Syntax	string.urlDecode (string)Params	string is a string to be converted from URL-safe encoding to plain ASCII.Action	Decodes any escaped characters in the string into their standard representation.Returns	The resulting string.Examples	string.urlDecode ("some%20illegal%20characters%3A%20%2F%20%24%20%26%20%25")		"some illegal characters: / $ & %"See Also	"string.urlEncode"
