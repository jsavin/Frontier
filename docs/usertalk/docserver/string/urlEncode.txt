#title "string.urlEncode"Syntax	string.urlEncode (string)Params	string is a string to be converted to URL-safe encodingAction	Encodes any characters that are illegal in URLs into their escaped form.Returns	The resulting string.Examples	string.urlEncode ("This is a string with some illegal characters: / $ & %")		"This%20is%20a%20string%20with%20some%20illegal%20characters%3A%20%2F%20%24%20%26%20%25"See Also	"string.urlDecode"
