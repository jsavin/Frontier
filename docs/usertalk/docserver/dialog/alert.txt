#title "dialog.alert"Syntax	dialog.alert (message)Params	message is a string containing the message to be displayed in the dialog.Action	Sounds the speaker and displays a dialog containing message and an "OK" button. It then waits for the user to click on the button.Returns	TrueExamples	dialog.alert ("Key file is missing. Cannot proceed!")		true	dialog.alert ("Can't delete the Finder!")		trueNotes	This verb offers the user only one response: OK.	Use this dialog to inform the user of a change, an abnormal situation, or an error from which you can't recover. For more routine notification, use dialog.notify.See Also	"dialog.notify"
