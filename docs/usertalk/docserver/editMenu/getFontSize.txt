#title "editMenu.getFontSize"Syntax	editMenu.getFontSize ()Params	None required.Action	Gets the font size of the selected item.Returns	The size of the font.Examples	edit (@examples.setFontTest)		true	Select the first line of text in the editing window. Now type and execute:		editMenu.getFontSize ()			12Notes	Applied to a word processing text window, this verb affects selected text or, if there is no selection, the next text entered. Applied to an outline or table window, it affects the entire contents of the window.See Also	"editMenu.setFontSize"
