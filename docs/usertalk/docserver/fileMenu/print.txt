#title "fileMenu.print"Syntax	fileMenu.print ()Params	None requiredAction	Prints the target Frontier window without user intervention.Returns	True if it is able to print, false otherwise.Examples	Open examples.letter. Type and execute:		fileMenu.print ()			true	Open two or three windows, one of which is system.verbs.builtins. Make sure that system.verbs.builtins is not the frontmost window. Now type and execute:		target.set (@system.verbs.builtins);		fileMenu.print ();		target.clear ()			true  	The contents of the system.verbs.builtins window prints regardless of what window is frontmost, demonstrating that the fileMenu verbs operate on the target window, not necessarily the topmost window.
