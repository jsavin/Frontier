#title "fileMenu.saveCopy"Syntax	fileMenu.saveCopy (path)Params	path is a full path name to the file in which you wish to save a copy of the current version of the Frontier root file.Action	Saves a copy of the current version of the Frontier database in the file pointed to by path, overwriting the contents of such a file if it exists, without confirmation.Returns	TrueExamples	fileMenu.saveCopy ("System:Frontier:Backups:My Root Copy")		trueErrors	If a disk error occurs during this process,  an error message is generated and the script terminates.Notes	fileMenu.saveCopy creates a compact version of the file.See Also	"fileMenu.save"
