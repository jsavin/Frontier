#title "fileMenu.open"Syntax	fileMenu.open (path, hidden = false)Params	path is a full path name to the Frontier document file you wish to open.	If hidden is provided and is true, the window for the object will be opened invisibly.Action	Opens the indicated file and performs the approprate actions (e.g., run a desktop script file, import an export file, and so forth).Returns	The address of the window containing the newly-opened objectExamples	fileMenu.open ("d:\\frontier\\members.root")		@["d:\\frontier\\members.root"]Notes	This verb results in the same action as opening the file with the Open command from the File menu, except that it skips the dialog that asks the user to locate the desired file.See Also	"fileMenu.new"	"fileMenu.close"
