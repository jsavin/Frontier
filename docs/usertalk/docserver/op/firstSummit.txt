#title "op.firstSummit"Syntax	op.firstSummit ()Params	None requiredAction	Moves the bar cursor to the first summit-level heading in the target outline window.Returns	TrueExamples	Open examples.Sample Outline 1 and position the bar cursor anywhere but the top summit heading, then execute:		op.firstSummit ()			true  	Notice that the cursor moves to the first summit-level heading in the outline.Notes	Frontier, unlike many outliners, permits an unlimited number of summit-level headings.	This verb is useful when you wish to use op.visit to traverse the entire outline or script.
