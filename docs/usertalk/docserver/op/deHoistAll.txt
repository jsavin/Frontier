#title "op.deHoistAll"Syntax	op.deHoistAll ()Params	None requiredAction	Reverses the effects of all hoist operations which have not yet been balanced by a call to op.deHoist.Returns	True unless no hoist operations are pending when it is called, in which case it returns false.Examples	In examples.Sample Outline 2, put the bar cursor on "Subhead 1.1." Now execute the following line three times:		op.hoist ()			true  	The display should show only Subhead 1.1.1.1. Now execute:		op.deHoistAll ()			true 	The outline should return to its original display.See Also	"op.hoist"
