#title "op.wipe"Syntax	op.wipe ()Params	None requiredAction	Deletes every heading in the target outline, leaving a single, blank summit.Returns	TrueExamples	With either examples.Sample Outline selected, execute:		op.wipe ()			true	and observe the result.Notes	op.wipe performs a Clear operation on the outline, not a Cut. The contents of the outline are therefore not available to paste into another outline.See Also	"op.deleteLine"	"op.deleteSubs"
