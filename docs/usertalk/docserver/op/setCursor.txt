#title "op.setCursor"Syntax	op.setCursor (marker)Params	marker is a number previously obtained with a call to op.getCursor.Action	Restores cursor to the same headline it was on when op.getCursor was called to place a value into marker.Returns	True unless the marker no longer exists or wasn't obtained with op.getCursor, in which case it returns false.Examples	In examples.Sample Outline 1, position the bar cursor on "Summit 2" and then execute:		origLine = op.getCursor ();		op.firstSummit ();		op.demote ();		op.setCursor (origLine)	This ensures that the bar cursor is positioned where it was before the op.demote operation was initiated, even though Summit 2 is at a different level then it was when we used op.getCursor.Errors	If the heading associated with the marker no longer exists or isn't a marker that was obtained via op.getCursor, this verb returns false.Notes	This verb is primarily used for returning the cursor to its position after executing a script that changed the cursor location.See Also	"op.getCursor"
