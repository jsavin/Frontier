#title "op.newOutlineObject"Syntax	op.newOutlineObject (s, adr)Params	s is a string that becomes the contents of the new outline object.	adr is the address of the outline object to create.Action	Creates a new outline object containing the string s.Returns	TrueExamples	op.newOutlineObject ("Foo", @temp.testOutline)		true	op.newOutlineObject ("Foo\r\tBar\r\tBaz", @temp.testOutline2)		trueNotes	The text is assumed to be tab-indented.	This verb is new in Frontier 5.1.3.See Also 	"wp.newTextObject"	"script.newScriptObject"
