#title "op.demote"Syntax	op.demote ()Params	None requiredAction	Moves all siblings following the current heading to the right, reducing their level in the outline.Returns	True unless the current heading has no siblings to move, in which case it returns false.Examples	Use examples.Sample Outline 1. Place the bar cursor at the first summit and then execute:		op.demote ()			true  	Notice that "Summit 2" and "Summit 3" move to the right, as do all of the subheads under "Summit 2." Undo this action.		Use examples.Sample Outline 2. Place the bar cursor on "Subhead 1.1.1" and then execute:		op.demote ()			false  	The current heading has no siblings beneath it in the outline.Errors	An attempt to demote a heading with no siblings beneath it in the outline returns a value of false but it is not an error.See Also	"op.promote"
