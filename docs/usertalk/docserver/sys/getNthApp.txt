#title "sys.getNthApp"Syntax	sys.getNthApp (n)Params	n is the index of the running application whose name you want returned.Action	Determines the name of the nth running application.  Indexes start at 1.Returns	The name of the application.Examples	sys.getNthApp (2)		UserLand FrontierPlatform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"sys.countApps"
