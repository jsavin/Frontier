#title "sys.appIsRunning"Syntax	sys.appIsRunning (id)Params	id is a string4 containing the signature of a Macintosh application, or a string containing an application's name or file system path.Action	Determines whether the application identified by the signature, name or path in id is running.Returns	True if the application is running, false if it is notExamples	sys.appIsRunning ('LAND')		true // Of course Frontier is running!	sys.appIsRunning ("Finder")		true // The Finder is usually a good bet too.	sys.appIsRunning ('MOR2')		true	'MOR2' is the ID for Symantec's MORE program.Platform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"file.creator"
