#title "sys.appIsIACAware"#platform "MacOS"Syntax	sys.appIsIACAware (path)Params	path is the file system path to an application.Action	Determines whether the application at path is equipped to receive IAC messages.Returns	True if the application is IAC-aware, false if it is not.Examples	sys.appIsIACAware ("System:Frontier 1.0:UserLand Frontier")		true // Of course Frontier is IAC-aware!	sys.appIsIACAware ("System:TeachText")		true	sys.appIsIACAware ("System:Ancient Apps:HabaDex)		false // Few applications released before System 7 are IAC aware.Platform Notes	This verb is only implemented in the Mac OS version of Frontier.
