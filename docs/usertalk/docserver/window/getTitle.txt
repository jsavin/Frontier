#title "window.getTitle"Syntax	window.getTitle (name)Params	name is the name of a window, or the address of a database object.Action	Retrieves the current title of a window.Returns	A string containing the current title of the window. If the specified window is not open, the empty string is returned.Examples	window.getTitle (@notepad)		"people.dmb.notepad"	window.setTitle ("root", Frontier.getFilePath ()); window.getTitle ("root")		"System:Frontier 1.0:Frontier.root"	window.getTitle (@scratchpad)		\""	The scratchpad window is not currently open.Notes	Normally, a window's title corresponds to its database address or is a special name such as Quick Script. But the "window.setTitle" verb can be used to establish a different title for a window.See Also	"window.setTitle"
