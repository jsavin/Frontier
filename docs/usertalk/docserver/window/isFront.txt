#title "window.isFront"Syntax	window.isFront (title)Params	title is the name of the window we want to determine as being the frontmost window.Action	Determines if the window is the frontmost window in Frontier.Returns	True if the window is frontmost, false if it is not or if no window named title is open.Examples	edit (@examples.funStuff);	window.isFront ("examples.funStuff")		trueSee Also	"window.frontmost"
