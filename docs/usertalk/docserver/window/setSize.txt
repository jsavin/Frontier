#title "window.setSize"Syntax	window.setSize (title, width, height)Params	title is the name of an open window.	width is the width to which you wish to set the window, in pixels.	height is the height to which you wish to set the window, in pixels.Action	Sets the size of the window so that it is width pixels wide and height pixels high.Returns	True if the window is open, false otherwiseExamples	window.setSize (window.frontmost (), 370, 200)		trueNotes	Frontier will not allow a window to be sized larger than the desktop area. Every window also has a minimum size that is enforced. It will limit each dimension given to window.setSize to ensure the window will fit on the desktop.See Also	"window.getSize"	"window.setPosition"	"window.zoom"
