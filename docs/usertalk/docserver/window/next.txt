#title "window.next"Syntax	window.next (title)Params	title is the name of the window we want to use as the reference point for finding the next window in the list of open windows.Action	Identifies the window that is immediately "behind" the window.Returns	The title of the window "behind" the window named title. If title is the rearmost window, this verb returns the empty string, " ".Examples	Open both examples and examples.funStuff. Make sure examples is frontmost. Now type and execute:		window.next ("examples")			"examples.funStuff"	Open both examples and examples.funStuff. Make sure examples.funStuff is frontmost. The example below uses a Frontier verb to find out what window is on top of the list. Type and execute:		window.next (window.frontmost ()) 			"examples"See Also	"window.visit"
