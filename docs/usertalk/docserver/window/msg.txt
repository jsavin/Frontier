#title "window.msg"Syntax	window.msg (string)Params	string is the message to be sent to the frontmost window.Action	Displays string in the message area of the frontmost window.Returns	TrueExamples	edit (@examples);	window.msg ("I'm a table window!")		true	The message "I'm a table window!" displays in the message area of the window in which examples is displayed.Notes	All Frontier's editing windows have a message area and can be the target for this verb.	If there are no other windows open, this verb displays string in the message area of the Quick Script window, but you may have to look very quickly to see it since the return value of true replaces it almost immediately.See Also	"msg"
