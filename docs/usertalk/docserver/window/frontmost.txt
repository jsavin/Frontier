#title "window.frontmost"Syntax	window.frontmost ()Params	None required.Action	Determines the title of the window that is frontmost.Returns	A string containing the title of the frontmost window.Examples	With the examples window open and frontmost, type and execute:		window.frontmost ()			"examples"	With the examples.funStuff window open and frontmost, type and execute:		window.frontmost ()			"examples.funStuff"Notes	If the frontmost window contains a database object, the title can be coerced to an address and used in conjunction with other Frontier verbs - not just window verbs. To see if the title can be used in this way, use "defined" as follows:		title = window.frontmost ();		if defined (title^) // it can be used as an address		addr = address (title)See Also	"window.isFront"
