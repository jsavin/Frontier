#title "inetd.stopOne"Syntax	inetd.stopOne (adrDaemonTable)Params	adrDaemonTable is the address of a table containing information on the service to stop.Action	Stops listening on the indicated port.Returns	True.Examples	inetd.stopOne (@user.inetd.config.http)		trueNotes	This verb generates a scriptError if the service hasn't already been started.See Also	"inetd.stop"	"inetd.startOne"
