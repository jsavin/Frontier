#title "inetd.isDaemonRunning"Syntax	inetd.isDaemonRunning (adrDaemonTable)Params	adrDaemonTable is the table of information about the specified inetd daemon.Action	Checks to see if the specified daemon is running.Returns	True if the daemon is running, false otherwise.Examples	inetd.isDaemonRunning (@user.inetd.config.http) //is the webserver running?		trueSee Also	"inetd.startOne"	"inetd.stopOne"
