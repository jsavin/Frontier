#title "defined"Syntax	defined (value)Params	value is a database object whose existence you wish to confirm.Action	Determines whether the object exists.Returns	True if the object exists, false otherwiseExamples	defined (examples.testText)		true // It's there	local (s = "testText");	defined (examples.[s])		true // An item named testText is in the examples table.	defined (examples[99])		false // There aren't 99 items in the examples table.Notes	This verb is useful to validate an address or to see if an object exists before attempting to operate on it.
