#title "namedElement"#platform "MacOS"Syntax	namedElement (class, name, container)Params	class is a string4 identifying the Apple Object Model class.	name is a string specifying the name of the element being sought.	container is the specifier of the object in which this verb specifies an element.Action	Obtains a specifier for the element named name of class in container.Returns	The object specifier of the named item.Examples	namedElement (cWindow, "Press Release", 0)		»  (specifies the window named "Press Release")Notes	To indicate the nil container, use the number zero.	This verb is implemented as a small script that calls setObj, to which it is closely related.See Also	"setObj"	"nthElement"
