#title "rollBeachBall"Syntax	rollBeachBall ()Params	None required.Action	Changes the Frontier beachball cursor to the next position in its rotation.Returns	TrueExamples	rollBeachBall ()		true	x = 0;	for x = 1 to 1000 \{msg (x);	rollBeachBall ()\}		true	Script displays numbers from 1 to 1000 and rolls the beachball cursor as it does so.Notes	It's a good idea to roll the beachball during a time-consuming process to give the user some feedback.
