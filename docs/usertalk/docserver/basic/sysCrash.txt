#title "sysCrash"Syntax	SysCrash ()Params	None requiredAction	Crashes Frontier into the low-level system debugger, if present.Returns	True, once the debugger is exited and control is returned to Frontier.Examples	syscrash (); msg ("back from the dead!")		"back from the dead!" is displayed in the About WindowNotes	This is an advanced Frontier verb of primary interest to implementers and advanced scripters. It is not necessary to understand it to use Frontier effectively for most tasks.	This verb is intended primarily for debugging purposes.	If no debugger is present in the system, a bomb box results, requiring a system restart. If you're not sure that a debugger is running, don't use this verb!See Also	"scriptError"
