#title "close"Syntax	close (address)Params	address is an address value that points to the object in the database whose editing window you wish to close.Action	Closes the window in which the object at address is displayed and un-sets the target.Returns	True if the object's window was open or the object at address was the target, false otherwise.Examples	edit (@examples.testOutline)		true	close (@examples.testOutline)		true	The second statement closes the window opened by the first.Notes	This verb operates similarly to window.close, except that the latter does not change the target. 	This verb essentially undoes the effect of edit.	If a target other than address has been set, it remains in effect.See Also	"target.clear"	"window.close"
