#title "nameOf"Syntax	nameOf (value)Params	value is a database object whose name you wish to determine.Action	Determines the name of the specified object.Returns	A string containing the name of the object.Examples	nameOf (examples.testText)		"testText"	nameOf (examples.["newItem"])		"newItem"	Note that it returns a name even though the object doesn't exist.		nameOf (examples[1])		"age" // "age" is the first item in the examples table, as sorted.			x = \{'font': "Geneva"\}; nameOf (x [1])		"font"	See Notes.Notes	The nameOf verb can also be used to determine the key of an item in a record value.
