#title "abs"Syntax	abs (number)Params	number is a number whose absolute value you wish to find.Action	Calculates the absolute value of number, where absolute value is defined as number without any leading sign.Returns	The absolute value of number.Examples	abs (43)		43	abs (-43)		43	abs (-3.2)		3.2Notes	number can be any of the following types: charType, intType, longType, singleType, doubleType, or fixedType.
