#title "ubase.getFilePath"Syntax	ubase.getFilePath (fnum)Params	fnum is the number which identiﬁes a uBASE database while it is openReturns	The path to the ﬁle containing the indicated database.Examples	for i = 1 to ubase.countFiles ()		ª msg (ubase.getFilePath (ubase.nthFile (i))	Brieﬂy displays the pathname of each open database ﬁle.Errors	An error is produced if uBASE is not running or if fnum does not identify an open database.Platform Notes	uBASE runs only on Mac OS and is not a supported component of Frontier 5.0,See Also	"ubase.nthFile"	"ubase.countFiles"
