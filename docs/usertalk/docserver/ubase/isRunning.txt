#title "ubase.isRunning"Syntax	ubase.isRunning ()Params	None.Action	Determines whether uBASE is running.Returns	True if uBASE is running on the same Macintosh as the script, false otherwise.Examples	Platform Notes	uBASE runs only on Mac OS and is not a supported component of Frontier 5.0,Notes	This verb is seldom used.  It has been retained for compatibility with existing scripts.See Also	"ubase.launch"
