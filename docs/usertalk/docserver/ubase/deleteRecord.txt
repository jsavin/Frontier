#title "ubase.deleteRecord"Syntax	ubase.deleteRecord (fnum, key)Params	fnum is the refnum for a uBASE file containing a record to be deleted. 	key is the key identifying a record.Action	Deletes the indicated record from the indicated database. This action cannot be undone.Returns	True if the record was deleted; false if the record was not in the database or could not be deletedExamples	key = ubase.getFirstRecord (fnum)	for i = 1 to ubase.countRecords (fnum)		nextKey = ubase.getNextRecord (fnum, key)		ubase.deleteRecord (fnum, key)		key = nextKey	Deletes all the records from the database referenced by fnum (which may not be a good idea!)Errors	An error is produced if uBASE is not running or if fnum does not identify an open database.Platform Notes	uBASE runs only on Mac OS and is not a supported component of Frontier 5.0,See Also	"ubase.addRecord"
