Returns zero if fewer than n databases are open.Examples	for n = ubase.countFiles () downto 1		» ubase.closeFile (ubase.nthFile (n))	Closes all open database files.Errors	An error is produced if uBASE is not running.Platform Notes	uBASE runs only on Mac OS and is not a supported component of Frontier 5.0,Notes	The Þle identifiiers (usually called fnum in these descriptions) are small positive numbers.
