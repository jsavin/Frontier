#title "webserver.util.buildErrorPage"Syntax	webserver.util.buildErrorPage (short, verbose)Params	short is a string containing a short version of the error message to be displayed.	long is a string containing an explanation of the error message.Action	Builds an HTML error page.Returns	The resulting HTML error page.Examples	webserver.util.buildErrorPage ("404 Not Found", "The file foo.html could not be found.")		// &lt;HTML&gt;&lt;HEAD&gt;&lt;TITLE&gt;404 Not Found&lt;/TITLE&gt;&lt;/HEAD&gt;&lt;BODY&gt;&lt;H1&gt;404 Not Found&lt;/H1&gt;&lt;P&gt;The file foo.html could not be found.&lt;/P&gt;&lt;/BODY&gt;&lt;/HTML&gt;Notes	This verb is used internally by the webserver framework. It's called from "webserver.dispatch" and "webserver.server" when an error page needs to be returned to the HTTP client.See Also	"webserver.dispatch"	"webserver.server"	"webserver.util.buildResponse"
