#title "webserver.encodeArgs"Syntax	webserver.encodeArgs (adrTable)Params	adrTable is the address of a Frontier table that should be converted to a url-encoded string of name/value pairs.Action	Creates a string of url-encoded name/value pairs from a Frontier table.Examples	local (x, s);new (tableType, @x);x.foo = 1;x.bar = 2;x.baz = "Hi Joe";webserver.encodeArgs (@x)		"bar=2&baz=Hi+Joe&foo=1"See Also	"webserver.parseArgs"	"string.urlEncode"
