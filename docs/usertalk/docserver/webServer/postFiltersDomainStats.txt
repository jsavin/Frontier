#title "webserver.postFilters.domainStats"Syntax	webserver.postFilters.domainStats (pta)Params	pta is the address of the current page table.Action	Adds total time to render and bytes returned to the totals for this domain and increments the hits count by one.Returns	trueNotes 	This verb is new in Frontier 6.1.	One should probably never need to call this verb from a script. It's called from user.webserver.postFilters.domainStats.	The stats for each domain are stored in user.webserver.stats.domains. Each name in the table corresponds to a domain listed in config.mainResponder.domains. Each subtable contains bytes, hits, and ticks.	If user.webserver.prefs.flDomainStats is false, then these stats are not maintained.
