#title "wp.getRightMargin"Syntax	wp.getRightMargin ()Params	None required.Action	Determines the current setting of the right margin for the selection in the target document. If the selection is empty, this verb determines the current setting of the right margin for the paragraph in which the selection appears.Returns	A number indicating the number of pixels from the right edge of the ruler at which the right margin is set.Examples	edit (@examples.testText);	wp.getRightMargin ()		0	The right margin defaults to 0, which means it is at the right edge of the ruler.		edit (@examples.testText)		true	Drag the right margin marker in the editing window to the 5-inch mark. Type and execute:		wp.getRightMargin ()			120  	The example returns the margin in pixels (approximately 1-2/3 inches to the left of the right end of the ruler.See Also	"wp.getLeftMargin"	"wp.setLeftMargin"	"wp.setRightMargin"
