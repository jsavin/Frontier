#title "wp.getSelText"Syntax	wp.getSelText ()Params	None required.Action	Retrieves the selected text in the target window, if any.Returns	The selected string from the target window or the empty string if nothing is selected.Examples	edit (@examples.testText);	wp.setSelect (0, 0); \// Make sure nothing is selected	wp.getSelText ()	The return in the example above is the empty string; nothing is selected in the document window.		edit (@examples.testText);	wp.setSelect (33, 40)	wp.getSelText ()		variousSee Also	"wp.getSelect"	"wp.setSelect"
