#title "wp.getSelect"Syntax	wp.getSelect (addrStart, addrEnd)Params	addrStart is the address of an object where you wish to store the starting location for the selection in the target word processing window.	addrEnd is the address of an object where you wish to store the ending location for the selection in the target word processing window.Action	Identifies the starting and ending location of the selection in the target word processing window, storing the results in addrStart and addrEnd.Returns	TrueExamples	Select the first paragraph of examples.wpTester. Now type and execute:		wp.getSelect (@start, @end);		msg (start + ", " + end)			true	The About Frontier window displays "0, 91".Notes	If there is no selection, addrStart will be equal to addrEnd.See Also	"wp.getSelText"	"wp.setSelect"
