#title "wp.setTextMode"Syntax	wp.setTextMode (state)Params	state is a boolean that determines whether you are turning text mode on (if true) or off (if false).Action	Toggles textMode on and off for the target window. This verb is used primarily to make portions of a table or outline editable by word processing verbs.Returns	TrueExamples	edit (@examples.["Sample Outline 1"]);	wp.setTextMode (true);	wp.inTextMode ()		trueSee Also	"wp.inTextMode"
