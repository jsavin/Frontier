#title "wp.selectLine"Syntax	wp.selectLine ()Params	None required.Action	Causes the line containing the current selection to become the selection.Returns	TrueExamples	edit (@examples.testText)		true	Now select a word in the first line of the document or simply place the cursor on that line. Type and execute:		wp.selectLine ()			true	The first line of the document becomes the selection.Notes	If the cursor is on an empty line, no change in the selection occurs but the verb still returns true.See Also	"wp.setSelect"	"wp.getSelect"	"wp.getSelText"	"wp.selectParagraph"	"wp.selectWord"
