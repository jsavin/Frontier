#title "wp.newTextObject"Syntax	wp.newTextObject (s, adr)Params	s is a string that becomes the contents of the new wp-text object.	adr is the address of the wp-text object to create.Action	Creates a new wp-text object containing the string s.Returns	True.Examples	wp.newTextObject ("Foo", @temp.x)		true	The wp-text object at temp.x now contains the word "Foo."Notes	This verb is new in Frontier 5.0.See Also	"op.newOutlineObject"	"script.newScriptObject"
