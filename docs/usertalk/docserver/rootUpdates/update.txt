#title "rootUpdates.update"Syntax	rootUpdates.update (adrInRoot, flQuietMode=false)Params	adrInRoot is the address of an object in the object database to be updated.	flQuietMode is an optional boolean parameter. If it's true, all user interaction will be suppressed.Action	Connects to the server associated with this database and gets the latest new and changed parts.Returns	True if the update was successful. Generates a scriptError if there are errors that cause the update to fail.Examples	rootUpdates.update (@root) \//Update Frontier.root		//true	rootUpdates.update (@mainResponder) \//Update a guest database		//trueNotes	Every database that can be updated should have a table in user.rootUpdates.servers. 	Each table should contain the following:<ul>	<li>autobackup: true to backup the database before updating.	<li>dbname: the name of the object database.	<li>dialogs: true to present dialogs while updating.	<li>lastUpdate: gets set to the last time the database was updated.	<li>method: the XML-RPC method to call when updating.	<li>port: the port number the XML-RPC server is listening on. (Usually 80, the default HTTP port).	<li>serialNum: gets set to the serial number of the last update.	<li>server: the hostname or IP address of the XML-RPC updates server.	<li>URL: the URL of the log of new and changed parts, if any.	</ul>	Starting with Frontier 6.1, if you have user.prefs.rootUpdates.flShowUpdatesToUser set true, a complete list of updated parts will be kept in an outline. Details are <a href="http://frontier.userland.com/stories/storyReader$1766">here</a>.See Also	"rootUpdates.threadedUpdate"	"betty.rpc.client"	"tcp.httpClient"	<a href="http://frontier.userland.com/stories/storyReader$94">How to Update Frontier.root</a>.
