#title "target.clear"Syntax	target.clear ()Params	None required.Action	"Undoes" a call to target.set, returning the target to the default, according to what windows are open.Returns	False.Examples	Open examples.list1 and examples.letter.  Make sure examples.letter is the frontmost window.  Now type and execute:		msg (target.get ()); 		clock.waitSeconds (2);		target.set (@examples.list1);		msg (target.get ());		clock.waitSeconds (2);		target.clear ();		msg (target.get ())	We have now reset the target to its former, default status.Notes	You should be careful to call target.clear only if you are positive that you want the target reset to the default. This is often not the case. The normal procedure for reverting the target to its previous value is discussed in "target.set".	Every thread has its own target, so you do not need to protect the target with semaphores.	"target.set" (nil) is equivalent to target.clear ().
