#title "target.get"Syntax	target.get ()Params	None required.Action	Identifies the current target.Returns	The address of the current target.Examples	Open examples.list1 and examples.letter.  Make sure examples.letter is the frontmost window.  Now type and execute:		msg (target.get ());		clock.waitSeconds (2);		target.set (@examples.list1);		msg (target.get ())Notes	Every thread has its own target, so you do not need to protect the target with semaphores.
