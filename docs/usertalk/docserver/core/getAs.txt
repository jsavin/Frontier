#title "core.getAs"#platform "MacOS"Syntax	core.getAs (appID, obj, type)Params	appID is a value identifying the application to which this verb is addressed. It can be a string4 containing the application signature, a binary value obtained by calling "sys.browseNetwork" or a string containing a valid network address.	obj is the specification of the objects from which to obtain data.	type is a string4 identifying the datatype that should be used to represent the contents of the objects.Action	Instructs the application identified by appID to extract data of the indicated type from the objects specified by obj.Returns	A value of the indicated type representing the data of obj. If obj specifies more than one object, returns a binary value containing a list of values, each being the data for one object.Examples	Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This is a low-level verb intended to be used only with applications that support the Core suite of Apple Events. Typically, an application's verb table will include high-level verbs that correspond to all of the events that it supports, so scripts should 	not have to call the core verbs directly.See Also	"core.get"	"getAppleListItem"
