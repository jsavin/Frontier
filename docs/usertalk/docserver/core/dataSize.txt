#title "core.dataSize"#platform "MacOS"Syntax	core.dataSize (appID, obj, type)Params	appID is a value identifying the application to which this verb is addressed. It can be a string4 containing the application signature, a binary value obtained by calling "sys.browseNetwork" or a string containing a valid network address.	obj is the specification of the objects whose data size you wish to retrieve.	type is a string4 identifying the datatype that should be used to represent the data of the objects.Action	Instructs the application identified by appID to retrieve the size of the data contained in the objects specified by obj.Returns	The size of the data. If obj specifies more than one object, returns a binary value containing a list of numbers, each being the size of one object's data.Examples	Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This is a low-level verb intended to be used only with applications that support the Core suite of Apple Events. Typically, an application's verb table will include high-level verbs that correspond to all of the events that it supports, so scripts should 	not have to call the core verbs directly.See Also	"core.getAs"	"getAppleListItem"
