#title "core.saveAs"#platform "MacOS"Syntax	core.saveAs (appID, obj, file, type)Params	appID is a value identifying the application to which this verb is addressed. It can be a string4 containing the application signature, a binary value obtained by calling "sys.browseNetwork" or a string containing a valid network address.	obj is the specification of the objects to be saved.	file is the full file system path to the file in which to save the objects.	type is a string4 value identifying the file type for the document.Action	Instructs the application identified by appID to save the objects specified by obj to file in the specified format.Returns	TrueExamples	Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This is a low-level verb intended to be used only with applications that support the Core suite of Apple Events. Typically, an application's verb table will include high-level verbs that correspond to all of the events that it supports, so scripts should 	not have to call the core verbs directly.See Also	"core.save"
