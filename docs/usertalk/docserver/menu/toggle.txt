#title "menu.toggle"Syntax	menu.toggle (addr)Params	addr is the Object Database address of the menu to be toggled.Action	If the menu is not currently in the menubar, adds it. If the menu is in the menubar, removes it.Returns	True if the toggle is successful, false otherwise.Examples	menu.toggle (@system.menus.menubar)		trueErrors	If addr points to a table entry that is not a menu, an error message results.Notes	This verb is implemented as a script.See Also	"menu.isInstalled"	"menu.install"	"menu.remove"
