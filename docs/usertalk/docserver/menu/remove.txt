#title "menu.remove"Syntax	menu.remove (addr)Params	addr is the Object Database address of the menu you wish to remove from the menu bar.Action	Removes the indicated menu from the Frontier menu bar if it is there.Returns	True if a menu described at addr is found on the menu bar and removed, false otherwise.Examples	menu.remove (@suites.findreplace.menu)		trueNotes	If you install a suite menu with "menu.addSuite", you cannot delete it from the menu bar with menu.remove and the same argument you used to install it. This is because menu.remove does not deal with suites, only with individual menus.See Also	"menu.addSuite"	"menu.install"
