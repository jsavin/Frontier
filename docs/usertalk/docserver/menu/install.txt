#title "menu.install"Syntax	menu.install (addr)Params	addr is the Object Database address of the menu to be installed.Action	Adds the menu object at Object Database location addr to the Frontier menu bar, immediately to the left of the Window menu.Returns	True if the installation is successful, false otherwise.Examples	menu.install (@suites.findreplace.menu)		trueErrors	If addr points to a table entry that is not a menu, an error message results.Notes	This verb can be used to install multiple menus.See Also	"menu.isInstalled"	"menu.remove"
