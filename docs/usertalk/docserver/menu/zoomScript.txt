#title "menu.zoomScript"Syntax	menu.zoomScript ()Params	None requiredAction	Opens an editing window for the script of the menu at the current menu bar cursor, if any, complete with a zooming rectangle effect.Returns	True if a menu bar cursor exists and its script can be edited, false otherwise.Examples	menu.zoomScript ()		trueErrors	If the target window is not a menubar editing window, an error message will be generated.See Also	"menu.getScript"	"menu.setScript"
