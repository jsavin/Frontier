#title "speaker.playNamedSound"#platform "MacOS"Syntax	speaker.playNamedSound (name)Params	name is a string identifying the name of the 'snd ' resource to be played.Action	Plays the 'snd ' resource with the given name.Returns	True if the sound resource was found, false otherwiseExamples	speaker.playNamedSound  ("Clink-Klank")		trueNotes	The sound resource may exist in Frontier.root or anywhere in the System resource chain.See Also	"speaker.sound"
