#title "speaker.sound"Syntax	speaker.sound(duration, amplitude, frequency)Params	duration is the length of time for which the sound should be generated, in sixtieths of a second.	amplitude is a number between 0 and 255 used to regulate the volume of the sound.	frequency is a number indicating the frequency (pitch) of the tone to be used.Action	Activates the speaker for the indicated duration, making the sound identified by frequency at a volume determined by amplitude.Returns	TrueExamples	speaker.sound (2,200,15000)		true // This is the sound made by speaker.ouch.	speaker.sound (2,255,15000)		true // This is the ouch sound, as loud as possible.	Open the examples table and position the bar cursor on examples.soundTester. Press Command-/ to execute this script. This little script lets you experiment with sounds, entering a duration, amplitude, and frequency, and then hearing the resulting 	sound.See Also	"speaker.ouch"
