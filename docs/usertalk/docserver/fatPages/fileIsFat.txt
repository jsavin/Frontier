#title "fatPages.fileIsFat"Syntax	fatPages.fileIsFat (f)Params	f is the path on disk to a file that may contain an embedded Frontier object.Action	Determines if the file contains an embedded Frontier object.Returns	True if an object is embedded, false if not.Examples	fatPages.fileIsFat (Frontier.pathString + "Read Me.html")		false	fatPages.fileIsFat (Frontier.pathString + "Extras" + file.getPathChar () + "ODBC" + file.getPathChar () + "extensions.odbc.fttb")		trueSee Also	"fatPages.dataIsFat"
