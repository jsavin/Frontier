#title "fatPages.dataIsFat"Syntax	fatPages.dataIsFat (adrText)Params	adrText is the address of a string that may contain an embedded Frontier object.Action	Determines if the string pointed to by adrText contains an embedded Frontier object.Returns	True if a Frontier object is embedded, false otherwise.Examples	local (s = file.readWholeFile (Frontier.pathString + "Read Me.html"));fatPages.dataIsFat (@s)		false	local (s = file.readWholeFile (Frontier.pathString + "Extras" + file.getPathChar () + "ODBC" + file.getPathChar () + "extensions.odbc.fttb"));fatPages.dataIsFat (@s)		trueSee Also	"fatPages.fileIsFat"
