#title "fatPages.importFatFile"Syntax	fatPages.importFatFile (f)Params	f is the path of the file to importAction	Imports the specified Fat Page and loads it into the ODB, with no user confirmation.Returns	The address of the object that was imported, or nil if the file contains a valid fat page that doesn't contain a Frontier objectExamples	fatPages.importFatFile ("C:\\Program Files\\Frontier\\rootUpdates.fttb")		@workspace.newPartsErrors	An error will be generated if the file does not exist or is not a valid Fat Page.Notes	This verb is implemented as a script.	This verb is useful for importer scripts that want to import many Fat Pages without having the user confim each one.See Also	"fatPages.getFromFile"	"export.sendObject"
