#title "fatPages.getFromFile"Syntax	fatPages.getFromFile (f)Params	f is the path of the file to importAction	Imports the specified Fat Page and loads it into the ODB, with user confirmation, and opens a window containing the object.Returns	TrueExamples	fatPages.getFromFile ("C:\\Program Files\\Frontier\\rootUpdates.fttb")		trueErrors	An error will be generated if the file does not exist or is not a valid Fat Page.Notes	This verb is implemented as a script.See Also	"fatPages.getFromFile"	"fatPages.getPageData"	"export.sendObject"
