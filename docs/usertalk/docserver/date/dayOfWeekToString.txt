#title "date.dayOfWeekToString"Syntax	date.dayOfWeekToString (daynum)Params	daynum is a number between 1 and 7Action	Returns a string that corresponds to the day number.Returns	A day name.Examples	date.dayOfWeekToString (1)		"Sunday"	date.dayOfWeekToString (5)		"Thursday"Errors	If the number is not between 1 and 7, a scriptError is thrown.Notes	This verb can be easily localized by changing the list at user.prefs.dates.dayNames.	This verb is new in Frontier 5.1.4.See Also	"date.get"	"date.monthToString"
