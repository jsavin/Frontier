#title "date.yesterday"Syntax	date.yesterday (date)Params	date is a valid Frontier date or a string that can be coerced to a date.Action	Returns a date value exactly one day before the specified dateReturns	A date value exactly one day before the specified dateExamples	date.yesterday (clock.now())		"12/4/97; 10:20:57 PM"	date.yesterday (clock.now()) equals (clock.now () - 24*60*60)		trueNotesSee Also	"date.tomorrow"
