#title "date.day"Syntax	date.day (date)Params	date is an optional parameter, a valid Frontier date or a string that can be coerced to a date.Action	Returns the day from the date.Returns	The day from the date.Examples	date.day ()		12	date.day ("6/8/53")		8	date.day (934878454)		16	date.day (clock.now ())		12Notes	This verb is new in Frontier 5.1.3.See Also	"date.year"	"date.month"
