#title "date.get"Syntax	date.get (date, dayAddr, monthAddr, yearAddr, hourAddr, minuteAddr, secondAddr)Params	date is a date value (stored as an unsigned 32-bit value representing the number of seconds since midnight, January 1, 1904).	dayAddr is the address at which you wish to store the day component of the date.	monthAddr is the address at which you wish to store the month component of the date.	yearAddr is the address at which you wish to store the year component of the date.	hourAddr is the address at which you wish to store the hour component of the date.	minuteAddr is the address at which you wish to store the minute component of the date.	secondAddr is the address at which you wish to store the second component of the date.Action	Breaks the date into its component parts and stores them where directed.Returns	TrueExamples	date.get (clock.now (), @day, @month, @year, @hour, @minute, @second)		true  	Date components are stored in indicated local variables.See Also	"date.set"	"clock.now"
