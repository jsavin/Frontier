#title "date.month"Syntax	date.month (date)Params	date is an optional parameter, a valid Frontier date or a string that can be coerced to a date.Action	Returns the month from the date.Returns	The month from the date.Examples	date.month ()		8	date.month ("3/8/53")		3	date.month (734878454)		4	date.month (clock.now ())		8Notes	This verb is new in Frontier 5.1.3.See Also	"date.year"	"date.day"
