#title "date.tomorrow"Syntax	date.tomorrow (date)Params	date is a valid Frontier date or a string that can be coerced to a date.Action	Returns a date value exactly one day after the specified dateReturns	A date value exactly one day after the specified dateExamples	date.tomorrow (clock.now())		"12/6/97; 10:14:48 PM"	date.tomorrow (clock.now()) equals (clock.now () + 24*60*60)		trueNotesSee Also	"date.yesterday"
