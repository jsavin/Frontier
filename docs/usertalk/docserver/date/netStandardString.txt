#title "date.netStandardString"Syntax	date.netStandardString (date)Params	date is a valid Frontier date or a string that can be coerced to a date.Action	Returns an RFC 822 version of the specified dateReturns	An RFC 822 version of the specified dateExamples	date.netStandardString (clock.now())		"Sat, 06 Dec 1997 04:03:15 GMT"Notes	This verb is useful for implementing many Internet protocols, such as SMTP and HTTP
