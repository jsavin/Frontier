#title "date.year"Syntax	date.year (date)Params	date is an optional parameter, a valid Frontier date or a string that can be coerced to a date.Action	Returns the year from the date.Returns	The year from the date.Examples	date.year ()		1998	date.year ("6/8/53")		1953	date.year (934878454)		1933	date.year (clock.now ())		1998Notes	This verb is new in Frontier 5.1.3.See Also	"date.month"	"date.day"
