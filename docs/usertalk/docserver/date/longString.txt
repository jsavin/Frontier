#title "date.longString"Syntax	date.longString (date)Params	date is a valid Frontier date or a string that can be coerced to a date.Action	Returns a verbose string representation of the specified dateReturns	a verbose string representation of the specified dateExamples	date.longString (clock.now())		"Friday, December 05, 1997"See Also	"date.shortString"	"date.abbrevString"
