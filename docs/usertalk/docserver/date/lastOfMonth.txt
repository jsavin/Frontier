#title "date.lastOfMonth"Syntax	date.lastOfMonth (date)Params	date is a valid Frontier date or a string that can be coerced to a date.Action	Returns a date value corresponding to midnight on the last day of the specified monthReturns	A date value corresponding to midnight on the last day of the specified monthExamples	date.lastOfMonth (clock.now())		"12/31/97; 12:00:00 AM" // New year's eveSee Also	"date.firstOfMonth"	"date.nextMonth"	"date.prevMonth"
