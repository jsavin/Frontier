#title "people.setUserPassword"Syntax	people.setUserPassword (userName, password)Params	userName is the name of the a user whose password you want to set.	password is the new password for this user.Action	Sets the password for a given user.Returns	True if the user account exists and the password could be set, false if not.Examples	people.setUserPassword ("Bull Mancuso", "abc")		trueSee Also	"people.getUserPassword"
