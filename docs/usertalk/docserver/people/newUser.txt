#title "people.newUser"Syntax	people.newUser (userName, password, emailAddress)Params	userName is the name of the new user.	password is the new user's password.	emailAddress is the email address of the new user.Action	Creates a new user account with the specified information.Returns	True if successful. Returns false if the user already exists.Examples	people.newUser ("Bull Mancuso", "abc", "bull@mancuso.com")		trueSee Also	"people.deleteUser"
