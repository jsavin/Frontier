#title "Finder.bringToFront"Syntax	Finder.bringToFront ()Params	None required.Action	Makes the Finder the frontmost application.Returns	TrueExamples	Finder.bringToFront ()		» truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	You don't often need to use this verb in conjunction with the other Finder verbs. Those that should or must bring Finder to the front do so automatically.See Also	"sys.bringAppToFront"
