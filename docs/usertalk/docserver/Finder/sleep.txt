#title "Finder.sleep"Syntax	Finder.sleep ()Params	None required.Action	Causes a Macintosh Portable, Macintosh Power Book, or other system that understands the \"Sleep\" command to blank its display and enter power-conserving mode.Returns	TrueExamples	Finder.sleep ()		» truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"Finder.restart"	"Finder.shutDown"
