#title "export.addToLog"Syntax	export.addToLog (adr, URL, notes)Params	adr is the address of the object being imported.	URL is an optional parameter, the source of the object.	notes is an optional parameter, a string describing the object.Action	Logs the date and time that a fat page was imported. The logging is done according to the user's logging preferences.Returns	TrueNotes	This verb is implemented as a script.
