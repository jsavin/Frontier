#title "point.get"Syntax	point.get (point, haddr, vaddr)Params	point is a Macintosh pointType.	haddr is the address where the horizontal portion of the point is to be stored.	vaddr is the address where the vertical position of the point  is to be stored.Action	Copies the horizontal and vertical values of point into the other two arguments.Returns	TrueExamples	point.get (mouse.location (), @h, @v);	msg ("Mouse at " + h + " horizontal and " + v + " vertical.")		» trueNotes	This verb is useful for extracting information from point values that might be sent into Frontier by an IAC-aware application.See Also	"point.set"
