#title "file.lock"Syntax	file.lock (path)Params	path is a legal path name to the file you wish to lock.Action	Locks the file; keeping it from being modified.Returns	TrueExamples	file.lock ("C:\\Program Files\\Frontier\\sample.txt")	file.isLocked ("C:\\Program Files\\Frontier\\sample.txt")		true	file.unlock ("C:\\Program Files\\Frontier\\sample.txt")		file.lock ("System:tmp"); 	file.isLocked ("System:tmp")		trueNotes	If the file being locked is in an open folder in the Finder, the padlock symbol that denotes a locked file appears only if you close the folder and then re-open it.
