#title "file.close"Syntax	file.close (path)Params	path is a legal path name to the file you wish to close.Action	Closes the file.Returns	True if the file is open, false if the file is already closed or if path is a folder.Examples	file.close ("C:\\Frontier 5\\textfile.txt")		true	file.close ("System:System Folder:textfile")		trueNotes	You should always close any files you've opened before your script terminates.See Also	"file.readLine"	"file.endOfFile"	"file.open"
