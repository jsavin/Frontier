#title "file.getPath"Syntax	file.getPath ()Params	None requiredAction	Determines the default path currently in use by Frontier.Returns	Frontier's current default path as a string.Examples	file.getPath ()		"C:\\Program Files\\Frontier\\"	file.getPath ()		"System:Frontier 1.0:"	This folder is where the system looks first for any file you name without a path.Notes	Use this verb to save the current path before setting it.	You can change the current path using "file.setPath".	All partial paths apply to files in this folder or nested within it.See Also	"file.setPath"
