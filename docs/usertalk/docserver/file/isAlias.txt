#title "file.isAlias"#platform "MacOS"Syntax	file.isAlias (path)Params	path is a legal path name to the file or folder which you wish to determine to be an alias or not.Action	Determines whether the file named in path is an alias file.Returns	True if the file is an alias, false if it is any other kind of file.Examples	file.isAlias ("System:System Folder:Startup Items:UserLand Frontier alias")		true	file.isAlias ("System:")		falseSee Also	"file.newAlias"	"file.followAlias"
