#title "file.readWholeFile"Syntax	file.readWholeFile (f)Params	f is the path to the file that you want the contents of.Action	Returns a string containing the entire contents of the specified file.Returns	A string containing the entire contents of the specified file.Examples	file.readWholeFile ("C:\\Program Files\\Frontier\\sample.txt")		"Contents of sample.txt"Notes	This verb is implemented as a script.	This verb takes care of opening and closing the file, so you don't have to do it.See Also	"file.writeWholeFile"
