#title "file.volumeFromPath"Syntax	file.volumeFromPath (path)Params	path is a legal path name of a folder or file whose volume name you wish to isolate.Action	Extracts the name of the volume on which the item specified by path exists.Returns	The path of the volume.Examples	file.volumeFromPath ("C:\\Frontier\\Frontier.root")		"C:\\"	file.volumeFromPath ("System:")		System:	file.volumeFromPath ("System:System Folder:")		System:	file.volumeFromPath ("Work Disk:Documents:Non-Disclosure")		Work Disk:Notes	file.volumeFromPath interprets the characters to the left of the first colon as the volume name. There is no guarantee that the volume exists.See Also	"file.fileFromPath"	"file.folderFromPath"
