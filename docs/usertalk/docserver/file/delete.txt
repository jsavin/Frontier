#title "file.delete"Syntax	file.delete (path)Params	path is a legal path name to the file or folder you wish to delete.Action	Deletes the file or empty folder without confirmation.Returns	True if it was able to delete the file or folder, false otherwise.Examples	file.delete ("C:\\Program Files\\Frontier\\Copy of cactus.gif")		true	file.delete ("System:temp file") 		trueErrors	Attempting to delete a non-existent file will result in an error .	If the file is locked or busy, an error results. 	If the path names a folder that contains files or sub-folders, an error results.Notes	You may use file.delete to delete a folder if you are sure that the folder is empty.See Also	"file.deleteFolder"
