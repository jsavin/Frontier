#title "file.folderFromPath"Syntax	file.folderFromPath (path)Params	path is a legal path name to the file or folder whose folder name or nesting (i.e., intermediate folder levels) you wish to determine.Action	Extracts the name of the volume and folder (s) containing the item specified by path.Returns	The parent folder of the item at path, as a string.Examples	file.folderFromPath ("C:\\Program Files\\Frontier\\Frontier.root")		"C:\\Program Files\\Frontier\\"	file.folderFromPath ("C:\\Program Files\\Frontier\\")		"C:\\Program Files\\"	file.folderFromPath ("System:System Folder:Finder")		System:System Folder:	file.folderFromPath ("System:System Folder:Control Panels:Memory)		System:System Folder:Control Panels:	file.folderFromPath ("System:System Folder:") 		System:Notes	If a folder path is provided, file.folderFromPath returns the path to the parent folder.See Also	"file.fileFromPath"	"file.volumeFromPath"
