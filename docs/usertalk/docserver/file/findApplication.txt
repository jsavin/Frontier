#title "file.findApplication"Syntax	file.findApplication (creator)Params	creator is a string4 identifying of creator type of the application whose location is to be determined.Action	Determines the location of the application with the given creator type.Returns	The path to the application, if found, otherwise the empty string.Examples	file.findApplication ('BARC')		"System:Frontier 1.0:UserLand Utilities:BarChart:BarChart"Notes	All mounted volumes are searched, starting with the current system volume.	If more than one version of the application is present on a volume, the path to the newest version is returned.	The application whose path is returned is the same one that the Finder would launch to open a document with the indicated creator.See Also	"file.getFileDialog"
