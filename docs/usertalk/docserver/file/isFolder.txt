#title "file.isFolder"Syntax	file.isFolder (path)Params	path is a legal path name to the item whose character as a file or folder you wish to ascertain.Action	Enables distinguishing between folders and files.Returns	True if the object pointed to by path is a folder or a disk volume, false if it's a file.Examples	file.isFolder ("C:\\Program Files\\Frontier\\")		true	file.isFolder ("C:\\Program Files\\Frontier\\Frontier.root")		false	file.isFolder ("C:\\")		true		file.isFolder ("System:System Folder:")		true	file.isFolder ("System:System Folder:Finder")		false	file.isFolder ("System:")		true
