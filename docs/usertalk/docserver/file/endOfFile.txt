#title "file.endOfFile"Syntax	file.endOfFile (path)Params	path is a legal path name to an open file.Action	Determines if the end of the file has been reached.Returns	True if all text in the file has been read, false otherwise.Examples	file.endOfFile ("C:\\Program Files\\Frontier\\sample.txt")		true	file.endOfFile ("System:System Folder:textfile")		falseNotes	Call this before calling file.readLine to make sure it won't fail.	If path points to a file that is not open, it returns true.See Also	"file.open"	"file.readLine"	"file.close"
