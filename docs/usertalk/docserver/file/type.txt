#title "file.type"Syntax	file.type (path)Params	path is a legal path name to the file or folder whose type you wish to determine.Action	Determines the type of the file.Returns	The type of the file as a string4.Examples	file.type ("System:System Folder:Finder")		'FNDR'	file.type ("System:System Folder:System")		'zsys'	file.type ("System:System Folder:TeachText")		'APPL' 	All Macintosh applications have a file type of 'APPL'.Notes	Type is a string 4 value. You can change the type of a file in Frontier with "file.setType".	The type of a file determines how the application that created it interprets or deals with it.See Also	"file.setType"	"file.creator"	"file.setCreator"
