#title "file.getVersion"#platform "MacOS"Syntax	file.getVersion (path)Params	path is a path name of the file whose version you wish to determine.Action	Returns the application version of the file, excluding copyright information.Returns	The version of the file, as a string.Examples	file.getVersion ("System:System Folder:Finder") 		"7.0"	file.getVersion ("System:AppleLink Folder:AppleLink") 		"6.0.2"	Note that the version number is a string. In some cases, it has more than one decimal point. It should never be dealt with as if it were a numeric value.		file.getVersion ("UserLand Frontier")		"3.0"Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	Normally, only application files have versions.	You can use file.getVersion to provide status information to the user or to check for compatibility. (As versions change, an application's IAC verbs might change or grow.)	For a longer version string, use file.getFullVersion.See Also	"file.getFullVersion"	"file.setVersion"	"file.setFullVersion"
