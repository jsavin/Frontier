#title "file.isEjectable"Syntax	file.isEjectable (path)Params	path is the name of the volume to be identified as ejectable or not.Action	Determines whether the volume in path can be ejected.Returns	True if path indicates an ejectable volume, false otherwise.Examples	file.isEjectable ("G:")		true	file.isEjectable ("System:") « an internal drive		false	file.isEjectable ("System 7.0:") « a CD		true	file.isEjectable ("Untitled:") « a floppy		true	Floppy disks, CD ROMs, and removable cartridges are ejectable; hard disks are not.See Also	"file.eject"
