#title "file.sureFolder"Syntax	file.sureFolder (path)Params	path is a legal path name to the file or folder whose existence as a folder you wish to ensure.Action	Determines if the folder at path exists. If so, no action is taken. If not, the folder is created.Returns	TrueExamples	file.sureFolder ("C:\\Program Files\\Frontier\\backups\\")		true		file.sureFolder ("System:backups:")		trueNotes	Use this when you want to add something to a folder. It saves you from dealing with the errors that arise when you try to put a document into a non-existent folder.See Also	"file.sureFilePath"	"file.isFolder"	"file.newFolder"
