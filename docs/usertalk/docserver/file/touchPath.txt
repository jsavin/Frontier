#title "file.touchPath"Syntax	file.touchPath (path)Params	path is a legal path name to a file or folder whose path you want to touch.Action	Sets the modification date on every file and folder in path to the current date.Returns	FalseExamples	file.touchPath ("C:\\Program Files\\Frontier\\sample.txt")		false // don't be fooled; it workedNotes	This verb is implemented as a script.See Also	"file.modified"
