#title "file.eject"#platform "MacOS"Syntax	file.eject (path)Params	path is the name of a removable disk volume (generally a floppy disk or CD, but it also works with removable cartridge media).Action	Ejects a removable volume.Returns	True if it worked, false otherwiseExamples	file.eject ("C:")	file.eject ("Untitled:") // This is a floppy disk, no problem ejecting		true	file.eject ("System:") // This is a hard disk, can't be ejected		falseErrors	It is an error if Frontier cannot find the volume identified in path.Notes	Fixed disks and the startup volume cannot be ejected.See Also	"file.isEjectable"
