#title "file.unlock"Syntax	file.unlock (path)Params	path is a legal path name to the file you wish to unlock.Action	Unlocks the file and thus allows it to be modified.Returns	TrueExamples	file.unlock ("C:\\Program Files\\Frontier\\sample.txt")	file.isLocked ("C:\\Program Files\\Frontier\\sample.txt")		false		file.unlock ("System:tmp"); 	file.isLocked ("System:tmp")		falseNotes	Unlocking a file that is not locked does not result in an error.
