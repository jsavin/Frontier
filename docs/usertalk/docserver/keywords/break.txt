Script execution continues at the next statement following the looping construct, skipping any subsequent statements within the current loop body.Examples	fileloop (fName in folderPath)		if file.isLocked (fName)			lockedFileFound = true			break		++numberOfFiles	if lockedFileFound		msg ("Found a locked file.")	This is just a script fragment, so don't attempt to execute it.
