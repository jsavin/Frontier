#title "kernel"Syntax	kernel (identifier)Action	Invokes a function built into Frontier's kernel, one that is implemented in the program code rather than in scripts. The parameters to the script enclosing the kernel statement are passed on to the kernel function.Examples	on exists (path)		kernel (file.exists)	Calls to the "exists" script invoke the kernel function file.exists with the path parameter provided.Notes	The kernel call must be the only statement in the body of a script.	The kernel statement is intended primarily for creators of Frontier verb scripts (i.e., UserLand Software), and is not generally applicable to script writing.
