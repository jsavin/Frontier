#title "mainResponder.discuss.getMessageFromClient"Syntax	mainResponder.discuss.getMessageFromClient (client, port)Params	client is the IP address of the machine to be contacted.	port is the number of the port that the connection should be made to.Action	Retrieve the message currently being edited from the specified machine via xml-rpc.Returns	True.Examples	mainResponder.discuss.getMessageFromClient ("localhost", 80)		trueNotes	This script calls the editorial.returnMessage xml-rpc handler on the specified machine.	This script implements part of the server-side support for suites.editorial, a suite for editing discussion group messages remotely in the Frontier 6 outliner. It is available from the "Frontier Site".See Also	"betty.rpc.client"
