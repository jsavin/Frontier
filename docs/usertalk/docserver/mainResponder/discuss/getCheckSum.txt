#title "mainResponder.discuss.getCheckSum"Syntax	mainResponder.discuss.getCheckSum (msgnum, adrmemberinfo)Params	msgnum is the number identifying the message.	adrmemberinfo is the address of a member table in members.root.Action	Computes a checksum for the specified message.Returns	The computed checksum.Examples	mainResponder.discuss.getCheckSum (1, @default.users.[\"andre@userland.com\"])		9776Notes	Detailed information about mainResponder's discussion group format is available from the "Frontier Site".
