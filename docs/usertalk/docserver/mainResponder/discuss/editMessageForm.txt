#title "mainResponder.discuss.editMessageForm"Syntax	mainResponder.discuss.editMessageForm (msgnum)Params	msgnum is the number identifying the message.Action	Builds an HTML form for editing the discussion group message specified by msgnum.Returns	The generated HTML code.Examples	mainResponder.discuss.editMessageForm (1)Errors	If the member requesting the form is not the author of the message, an error message is generated.Notes	Detailed information about mainResponder's discussion group format is available from the "Frontier Site".See Also	"mainresponder.discuss.getMessageTable"
