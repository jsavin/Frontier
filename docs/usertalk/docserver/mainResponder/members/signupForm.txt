#title "mainResponder.members.signupForm"Syntax	mainResponder.members.signupForm ()Params	None.Action	Builds an HTML form with a Mail Address field for signing up as a member of a website.Returns	A string containing the generated HTML code.Examples	mainResponder.members.signupForm ()Notes	Call this script as a macro from your site's signup page.	The data entered into the form usually ends up being processed in mainResponder.members.checkMembership.	Detailed information about mainResponder's membership group format is available from the "Frontier Site".See Also	"mainResponder.members.checkMembership"	"mainResponder.members.logonForm"
