#title "mainResponder.members.getMembershipTable"Syntax	mainResponder.members.getMembershipTable (groupname)Params	groupname is either a string containing the name of a top-level table in members.root or the address of a table.Action	If groupname is a string, check if a top-level table with that name exists in members.root and return its address.	If groupname is an address, check if it's pointing to a table and return it.Returns	The address of the membership table.Examples	mainResponder.members.getMembershipTable (\"default\")		@["Macintosh HD:Apps:Frontier:Guest Databases:ops:members.root"].defaultErrors	If a membership table can't be located, an error message is generated.Notes	Detailed information about mainResponder's membership group format is available from the "Frontier Site".
