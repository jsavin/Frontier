#title "mainResponder.members.linkToMember"Syntax	mainResponder.members.linkToMember (groupname, memberkey)Params	groupname is either a string containing the name of a top-level table in members.root or the address of a table.	memberkey is the key identifying a member of the group specified by groupname. Usually, this is the member's email address.Action	Locate the member's sub-table in the members sub-table of the membership table and build a link to the member's profile page.Returns	A string containing the HTML code for the link.Examples	mainResponder.members.linkToMember (\"default\", "dave@userland.com")		&lt;a href="http://profiles.userland.com/$dave@userland.com">Dave Winer&lt;/a>Notes	If the member's real name is not known, memberKey is returned as plain text (i.e. not hot-linked).	Detailed information about mainResponder's membership group format is available from the "Frontier Site".See Also	"mainResponder.members.getMemberTable"
