#title "mainResponder.members.validMailAddress"Syntax	mainResponder.members.validMailAddress (mailaddress)Params	mailaddress is a string.Action	Perform a couple of basic checks to make reasonably sure that mailaddress contains a valid email address.Returns	True.Examples	mainResponder.members.validMailAddress ("dave@userland.com")		trueErrors	If mailaddress is found to be invalid, an appropriate error message is generated.
