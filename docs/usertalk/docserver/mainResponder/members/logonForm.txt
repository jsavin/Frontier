#title "mainResponder.members.logonForm"Syntax	mainResponder.members.logonForm (bgcolor)Params	bgcolor is a string specifying an HTML color code. Default: ivory.Action	Builds an HTML form with Mail Address and Password fields.Returns	A string containing the generated HTML code.Examples	mainResponder.members.logonForm ()Notes	Call this script as a macro from your site's logon page.	The data entered into the form usually ends up being processed in mainResponder.members.checkMembership.	Detailed information about mainResponder's membership group format is available from the "Frontier Site".See Also	"mainResponder.members.checkMembership"	"mainResponder.members.signupForm"
