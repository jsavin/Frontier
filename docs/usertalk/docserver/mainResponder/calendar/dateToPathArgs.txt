#title "mainResponder.calendar.dateToPathArgs"Syntax	mainResponder.calendar.dateToPathArgs (d)Params	d is a valid date.Action	Generates a string representation for d which is suitbable for use in URLs pointing into mainResponder-style calendar structures. The format is "YYYY/MM/DD".Returns	A special string representation of d.Examples	local (d = clock.now ())	mainResponder.calendar.dateToPathArgs (d)		"1999/04/01"Errors	If d is not a valid date or cannot be coerced to a date type, an error message is generated.Notes	Detailed information about mainResponder's calendar format is available from the "Frontier Site".See Also	"mainResponder.calendar.pathArgsToDate"
