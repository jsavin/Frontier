#title "mainResponder.calendar.getLastDay"Syntax	mainResponder.calendar.getLastDay (adrcalendar)Params	adrcalendar is the address of a calendar in the database.Action	Dive into the calendar structure and determine the date of the last calendar entry.Returns	The date of the last calendar entry.Examples	mainResponder.calendar.getLastDay (@scriptingNews)		"3/12/99; 12:00:00 AM"Errors	If adrcalendar does not point to a valid non-empty calendar structure, an error message is generated.Notes	It's safe for the calendar structure to contain non-numeric entries (e.g.#directives).	Detailed information about mainResponder's calendar format is available from the "Frontier Site".See Also	"mainResponder.calendar.getLastAddress"	"mainResponder.calendar.getMostRecentDay"	"mainResponder.calendar.getNextDay"	"mainResponder.calendar.getFirstDay"
