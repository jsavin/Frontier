#title "mainResponder.redirect"Syntax	mainResponder.redirect (url)Params	url is a string containing a HTTP URL.Action	Sets the value of the redirectUrl field of the current page table to url. This will cause mainResponder.respond to redirect the client to the specified URL.Returns	The specified URL.Examples	mainResponder.redirect ("http://news.userland.com/")Notes	Call this script whenever you need to redirect the client to another page from code that runs in the context of mainResponder.respond.
