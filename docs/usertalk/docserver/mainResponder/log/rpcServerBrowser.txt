#title "mainResponder.log.rpcServerBrowser"Syntax	mainResponder.log.rpcServerBrowser (lineCount, colors)Params	lineCount is the maximum number of lines to display.	colors is a list of two colors that are alternating HTML table row colors.Action	Generates HTML that displays the XML-RPC Server log.Returns	A string of HTML text.Examples	mainResponder.log.rpcServerBrowser (20, &#123;"papayawhip", "lemonchiffon"&#125;)		//&#60;table border="0" cellpadding="5" cellspacing="0">\r\t&#60;!-- 1 -->\r\t&#60;tr bgcolor="lemonchiffon">\r\t\t&#60;td height="28">...Notes	This verb is new in Frontier 6.1.	The name of the log in the log guest database is rpcServer.	Logging is turned on and off at user.betty.prefs.flKeepServerLog.
