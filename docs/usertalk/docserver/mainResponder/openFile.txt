#title "mainResponder.openFile"Syntax	mainResponder.openFile (foldername, filename)Params	foldername is a string containing the name of a sub-folder of Frontier's Guest Databases folder.	filename is a string containing the name of the file.Action	Opens or if neccessary creates a guest database with the specified name in the specified sub-folder of the Guest Databases folder. The top-level window of the guest database remains hidden.Returns	The full path to the file.Examples	mainResponder.openFile ("www", "logBrowser.root")		"Macintosh HD:Apps:Frontier:Guest Databases:www:logBrowser.root"
