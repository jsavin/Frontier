#title "clock.now"Syntax	clock.now ()Params	NoneAction	Retrieves the current date and time as set by the system clock.Returns	The date value corresponding to the current date and time in the system clockExamples	clock.now ()		9/6/91 ; 11:35:23 AM	(number (date ("1/1/2000")) - number (date ("12/31/1999"))) / (60 * 60)		24Note	Dates are stored internally as large integers, representing the number of seconds since 1/1/1904 at 12:00:00 AM.See Also	"clock.set"	"string.dateString"	"string.timeString"	"date verbs"
