#title "clock.idleTime"#platform "MacOS"Syntax	clock.idleTime ()Params	None requiredAction	Determines the number of sixtieths of a second (ticks) the system has been idle.Returns	A number indicating the number of ticks the system has been idle.Examples	clock.idleTime ()		333897	clock.idleTime ()/3600		67	The returned value indicates that the machine has been idle for 67 minutes.Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This verb is only supported if the IdleTime extension is installed.
