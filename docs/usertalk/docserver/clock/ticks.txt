#title "clock.ticks"Syntax	clock.ticks ()Params	None requiredAction	Determines the number of sixtieths of a second (ticks) the system has been operational since it was last started.Returns	A number indicating the number of ticks since the last computer startup.Examples	clock.ticks ()		333897	clock.ticks ()/3600		67	The returned value indicates that the machine has been running for 67 minutes.Notes	This verb is useful in performance benchmarking tests and for generating random numbers.
