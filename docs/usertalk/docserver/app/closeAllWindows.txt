#title "app.closeAllWindows"Syntax	app.closeAllWindows ()Params	None.Action	Closes all windows open that the application has open.Returns	True if all windows were closed.Examples	app.start ("MinApp"); app.closeAllWindows ()		falsePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	This verb is implemented as a script. You can examine the source code at system.verbs.builtins.app.closeAllWindows.	In any window has changed since it was opened or created, the application comes to the front and a confirmation dialog appears. To disable this interaction, call app.enableDialogs (false).See Also	"app.closeWindow"	"app.enableDialogs"
