#title "app.madeChanges"Syntax	app.madeChanges ()Params	None.Action	Determines if the target window has been modified since being opened or last saved.Returns	True if the target window has been changed since the last save, false otherwise.Examples	app.start ("MinApp"); app.madeChanges ()		true	app.start ("MinApp"); app.saveWindow ("")		true	app.start ("MinApp"); app.madeChanges ()		falsePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"app.saveWindow"
