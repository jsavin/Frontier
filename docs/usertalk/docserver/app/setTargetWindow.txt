#title "app.setTargetWindow"Syntax	app.setTargetWindow (title)Params	title is a string indicating which window is to become the target window.Action	All subsequent verbs apply to the target window.Returns	Returns the title of the target window. If it failed, the empty string is returned.Examples	app.start ("MinApp"); app.setTargetWindow ("Dave's email")		"Dave's email"	app.start ("MinApp"); app.setTargetWindow ("")		"Untitled 1"Platform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	If the title is empty, the target is set to the name of the frontmost window.See Also	"app.getTargetWindow"
