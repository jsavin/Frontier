#title "app.setFont"Syntax	app.setFont (fontName)Params	fontName is the name of a font.Action	Has the same effect as setting the font interactively. Varies from application to application.Returns	True if it worked, false if it didn't.Examples	app.start ("MinApp"); app.setFont ("Geneva")		truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"app.setFontSize"
