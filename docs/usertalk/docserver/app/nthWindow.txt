#title "app.nthWindow"Syntax	app.nthWindow (n)Params	n is a number indicating which window the script wants the title of.Action	Determines the title of the nth window.Returns	The title of the nth window.	Windows are ordered from front to back, so the first window is the frontmost one. If n is greater than the number of windows, the empty string is returned.Examples	app.start ("MinApp"); app.nthWindow (1)		"Dave's email"	app.start ("MinApp"); app.nthWindow (app.countWindows ())		"Untitled 1"Platform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"app.countWindows"
