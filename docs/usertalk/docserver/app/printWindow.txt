#title "app.printWindow"Syntax	app.printWindow ()Params	None.Action	Prints the contents of the target window.Returns	True if the application was able to print the contents of the target window.Examples	app.start ("MinApp"); app.printWindow ()		truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"app.newWindow"	"app.openWindow"	"app.closeWindow"	"app.saveWindow"	"app.moveWindow"	"app.revertWindow"	"app.selectWindow"	"app.setTargetWindow"
