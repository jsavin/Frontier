#title "app.getPicture"Syntax	app.getPicture (address)Params	address is the object database location that receives the picture.Action	Gets the selected items from the target window in the form of a Macintosh picture and stores the result at the indicated address.Returns	True if it worked, false otherwise.Examples	app.start ("BarChart"); app.getPicture (@scratchpad.x); edit (@scratchpad.x)		truePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Notes	Some applications cannot generate picture data, they return false when this verb is called.See Also	"app.getText"	"app.putPicture"
