#title "app.getTargetWindow"Syntax	app.getTargetWindow ()Params	None.Action	Determines which application window is the target window.Returns	Returns a string containing the title of the target window or the title of the frontmost window if the target window hasn’t been set. 	Returns the empty string if no windows are open.Examples	app.start ("MinApp"); app.getTargetWindow ()		"Untitled 1"Platform Notes	This verb is only implemented in the Mac OS version of Frontier.See Also	"app.setTargetWindow"
