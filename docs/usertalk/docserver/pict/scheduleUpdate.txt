#title "pict.scheduleUpdate"Syntax	pict.scheduleUpdate (seconds)Params	seconds is a number specifying the number of seconds to be established as the update interval for the target picture.Action	Establishes seconds as the frequency at which the target picture will recalculate any expressions it contains and update its display.Returns	TruePlatform Notes	This verb is only implemented in the Mac OS version of Frontier.Examples	pict.scheduleUpdate (13)		» trueNotes	This verb is relevant only to picture windows displaying pictures which in turn contain expressions.  Expressions are text objects that begin with an equals sign, followed by a valid UserTalk expression.See Also	"pict.expressions"
