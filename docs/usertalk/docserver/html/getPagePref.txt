#title "html.getPagePref"Syntax	html.getPagePref (pref, addr)Params	pref is the name of a directive	addr is the address of a pageAction	Returns the value of the specified directive for the specified page.Returns	The value of the specified directive for the specified pageExamples	html.getPagePref ("title", @websites.samples.shortStory)		\"Short Story"Notes	Use this verb to get a directive from a page that's not the one currently being rendered. To get a directive from a page that's currently being rendered, use "html.getPref".	This verb is implemented as a script.See Also	"html.getPref"
