#title "html.getGifHeightWidth"Syntax	html.getGifHeightWidth (f)Params	f is the path to a GIF file or, in 5.1.4 and greater, the object database address of a GIF.Action	Returns the height and width of the specified GIF image in pixels.Returns	The height and width of the specified GIF image in pixels as a list. Height is the first element in the list, width is second.Examples	html.getGifHeightWidth (@websites.samples.["#images"].windows)		\{60, 77}NotesSee Also	"html.getJpegHeightWidth"
