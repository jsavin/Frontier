#title "html.expandURLs"Syntax	html.expandURLs (s)Params	s is a string containing URLs to be expanded.Action	Expands all the URLs in a string.Returns	The string with expanded URLs.Examples	html.expandURLs ("http://www.scripting.com/")		"&lt;a href=\"http://www.scripting.com/\">http://www.scripting.com/&lt;/a>"	html.expandURLs ("No URLs in this string.")		"No URLs in this string."	html.expandURLs ("webmaster@userland.com")		"&lt;a href=\"mailto:webmaster\@userland.com\">webmaster\@userland.com&lt;/a>"	html.expandURLs ("ftp://ftp.userland.com/userland/ http://www.userland.com/")		"&lt;a href=\"ftp://ftp.userland.com/userland/\">ftp://ftp.userland.com/userland/&lt;/a> &lt;a href=\"http://www.userland.com/\">http://www.userland.com/&lt;/a>"Notes	This verb is new in Frontier 5.1.
