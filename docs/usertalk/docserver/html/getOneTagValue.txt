#title "html.getOneTagValue"Syntax	html.getOneTagValue (htmlText, tagName)Params	htmlText is a string containing HTML tags.	tagName is the name of the tag containing the value you want to get.Action	Gets the value enclosed by the tagName tag.Returns	A string, the value.Examples	html.getOneTagValue ("&lt;title>This is the title of the page&lt;/title>", "title")		"This is the title of the page"Notes	This verb does not reference the page table; it can be called any time.	This verb is implemented as a script.See Also	"html.getOneDirective"
