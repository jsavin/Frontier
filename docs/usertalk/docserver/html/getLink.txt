#title "html.getLink"Syntax	html.getLink (text, URL)Params	text is the text of the link as a string	URL is the target of the link as a stringAction	Returns an HTML anchor tag with a link to the specified URL.Returns	An HTML anchor tag with a link to the specified URLExamples	html.getLink (\"Frontier", "http://www.scripting.com/frontier5/")		"&lt;a href=\"http://www.scripting.com/frontier5/\"&gt;Frontier&lt;/a&gt;"Notes	This verb is implemented as a script.
