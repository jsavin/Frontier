#title "html.getOneDirective"Syntax	html.getOneDirective (directiveName, s)Params	directiveName is the name of the directive.	s is a string of text containing the directive or an outline containing the directive.Action	Finds the specified directive and gets its value.Returns	The value of the directive, or "" if the directive doesn't exist.Examples	html.getOneDirective ("title", string (websites.samples.default))		"Samples Site"	html.getOneDirective ("foo", string (websites.samples.default))		""See Also	"html.getPref"	"html.getPagePref"
