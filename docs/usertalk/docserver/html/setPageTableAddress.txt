#title "html.setPageTableAddress"Syntax	html.setPageTableAddress (adrPageTable)Params	adrPageTable is the object database address of the page table to use for the current page.Action	Sets the address of the current page table to adrPageTable.Returns	An address in system.temp.pageTableAddress where the address of the page table is stored.Examples	html.setPageTableAddress (@websites.["#data"])		@system.temp.pageTableAddresses.["194"]Notes	This verb is called by html.buildObject. It's a rare case when you might want to call this verb yourself.	This verb is new in 5.1.4.See Also	"html.getPageTableAddress"
