#title "html.getCurrentTemplateName"Syntax	html.getCurrentTemplateName (adrPageTable)Params	adrPageTable is the object database address of the current page table.Action	Gets the name of the template currently being used.Returns	A string, the name of the template.	If the #template object is being used, the returned string is "Default."Examples	html.getCurrentTemplateName (@websites.["#data"])		\"Default"Notes	This verb is useful for rendering <a href="http://www.scripting.com/frontier5/howtos/scalableContent.html">scalable content</a>.	Call this verb from your macros when they need to do different things based on which template is the current template.	This verb is new in Frontier 5.1.4.See Also	"html.getExtraTemplates"
