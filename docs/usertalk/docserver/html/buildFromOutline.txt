#title "html.buildFromOutline"Syntax	html.buildFromOutline (addr)Params	addr is the address of an outline of addresses of pagesAction	For each line in the outline, attempts to build the page at that address. If the page was built successfully, this verb deletes that line from the oultine.Returns	TrueExamples	Notes	To build an entire table, use "html.ftpTable".	This verb is implemented as a script.See Also	"html.ftpTable"
