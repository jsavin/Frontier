#title "html.getPref"Syntax	html.getPref (pref, adrPageTable)Params	pref is the name of a directive	adrPageTable is the optional address of the current page tableAction	Returns the value of the specified directive.Returns	The value of the specified directiveExamples	html.getPref ("title")		\"Short Story"Notes	To get a directive from a page that's not the one currently being rendered, use "html.getPagePref".	This verb is implemented as a script.See Also	"html.getPagePref"
