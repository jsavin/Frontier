#title "html.refGlossary"Syntax	html.refGlossary (name)Params	name is the name of a glossary item.Action	Look up the name in the glossary.Returns	The value of the glossary item.Notes	This verb is implemented as a script.	This verb is used internally by the website framework: it's rare that you would need to call this verb from a script.	To include a glossary item in a page, just surround it with &quot;double quotes&quot; -- Frontier will call html.refGlossary for you.
