Dialog Verbs

  • dialog.alert - Display an alert dialog.
  • dialog.ask - Get input from the user via dialog box.
  • dialog.confirm - Display a confirmation dialog.
  • dialog.fileInfo - Display a file information dialog.
  • dialog.getInt - Get an integer from the user via dialog.
  • dialog.getPassword - Get a user's password.
  • dialog.getValue - Get the value of an item in a dialog.
  • dialog.hideItem - Hide an item in a dialog box.
  • dialog.loadFromFile - Copy a dialog resource into Frontier.root.
  • dialog.notify - Display a notification dialog.
  • dialog.run - Run a dialog.
  • dialog.runFromFile - Run a dialog stored in a file.
  • dialog.runModeless - Run a modeless dialog.
  • dialog.setItemEnable - Enable or disable a dialog item.
  • dialog.setValue - Set the value of an item in a dialog.
  • dialog.showItem - Show an item in a dialog.
  • dialog.threeWay - Display a dialog with three buttons.
  • dialog.twoWay - Display a dialog with two buttons.
  • dialog.yesNo - Display a Yes/No dialog.
  • dialog.yesNoCancel - Display a Yes/No/Cancel dialog.
