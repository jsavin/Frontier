Frontier 9.5: ODBC for Macintosh

ODBC for Macintosh from the Tallent Communications Group

http://www.tallent.com/frontier/odbc/

The ODBC Extension allows a Frontier user to easily write cross-platform scripts for connecting Frontier to any ODBC compliant database system such as Oracle, Sybase, MS SQLServer, Access, Butler, and more. It consists of a suite of scripts and a DLL that work on Win32 and Mac PPC systems.

This is version 1.0b14r15, released May 1, 2004.

Installation

The ODBC extension is already installed in the copy of Frontier.root that ships with Frontier 9.5.

To configure ODBC, Jump to odbc.README and follow the instructions there.

Support

The ODBC extension is developed by the Tallent Communications Group and they provide support, including an ODBC users mailing list.

To get support, go to http://www.tallent.com/frontier/odbc/support.html
