Frontier 9.5: Proxy Users

If you're behind a proxy server, you'll need to add a startup file to the Frontier folder so that Frontier will know your proxy settings.

Using your preferred text editor, open the file named frontierStartupCommands.txt that's in the folder with the Frontier application.

Add to the top of the file:

new (tableType, @user.webBrowser.proxy);
user.webBrowser.proxy.domain = "mydomain";
user.webBrowser.proxy.port = myport;
user.webBrowser.proxy.username = "myusername";
user.webBrowser.proxy.password = "mypassword";

Replace mydomain with the domain name or IP address of your proxy server. Replace myport with the port number of your proxy server. Replace myusername with your username. Replace mypassword with your password.

If you don't know your settings, your network administrator should be able to help you.
