Frontier 9.5: AltiVec Support

Frontier 9.5 is the first version to include AltiVec support, for MacOS X users with G4 or G5 servers.

AltiVec is a feature of the G4 and G5 microprocessors used in newer Macs, which is designed increase performance for certain low-level processor operations.

This version of the Frontier kernel may provide a noticable increase in performance on busy servers, faster launch times, and greater responsiveness, even on servers with relatively light loads.

Hardware Requirements:

Support for AltiVec optimizations is only present in G4 and newer processors. If you attempt to run the AltiVec version of the Frontier kernel on older Macs, including G3 Macs, it will crash immediately. Crashes shouldn't result in any data loss, but it's safer to never attempt to run the AltiVec version on G3 or older Macs.

If you're unsure of which version to run, use the normal, non-AltiVec version.

How to Install:

To use the AltiVec version of the Frontier kernel, move the Frontier 9.5 AltiVec application file to the top-level of your Frontier application folder -- the same folder which contains the normal UserLand Frontier application, and use the Frontier 9.5 AltiVec version instead.
