# Third-Party Licences

This directory collects the licence texts for bundled third-party code and
resources:

- `RSA-MD5.txt` – RSA Data Security, Inc. MD5 Message-Digest Algorithm sample
  licence.
- `SSLeay-OpenSSL.txt` – Eric Young's original SSLeay/OpenSSL licence used by
  the SHA-1 implementation.
- `PCRE.txt` – PCRE regular expression library licence.
- `Apple-Sample-Code.txt` – Apple Sample Code licence covering MoreFiles,
  FSCopyObject, and similar samples.

All bundled third-party components are MIT-compatible. The previously bundled
GPL-licensed MySQL client code was removed as part of the GPLv2 → MIT
relicensing; the `mysql` verbs remain registered as headless stubs that return
a script error indicating the feature is not implemented on this platform.

`GPL-2.0-historical.txt` is the GPLv2 license text under which this project
was originally released. It is preserved for historical reference only and
does not apply to the current project — see `LICENSE` and `RELICENSING.md`.
